### Some Basics

Before we begin systematically learning Python programming, let us first introduce some basic computer knowledge. A computer hardware system usually consists of five major components: the **arithmetic logic unit (ALU)**, the **control unit**, **memory**, **input devices**, and **output devices**. The ALU and control unit together form what we commonly call the **central processing unit (CPU)**, whose function is to execute various operations and control instructions. As we mentioned earlier, a program is a collection of instructions, and writing a program is organizing a series of instructions in a certain way, then using these instructions to control the computer to do what we want. Memory can be divided into **internal memory** and **external memory**. The former is what we commonly call RAM, which is the storage space directly addressable by the CPU. During program execution, the corresponding data and instructions need to be loaded into memory. Input and output devices are often collectively referred to as I/O devices. Keyboards, mice, microphones, and cameras are typical input devices, while monitors, printers, and speakers are typical output devices. Currently, most computers we use follow the "von Neumann architecture," which has two key points: first, **the memory is separated from the CPU**; second, **data is encoded in binary**.

Binary is a "carry-on-two" counting system, which is essentially the same as the "carry-on-ten" counting system used by humans. Humans use the decimal system because we have ten fingers — when all ten fingers are used up, we can only use carrying to represent larger values. Of course, there are exceptions: the Mayans, possibly because they went barefoot year-round, used their toes as well, so they used a base-20 counting system. Based on this counting method, the Mayan calendar differed from the calendar we commonly use. According to the Mayan calendar, 2012 was the last year of the previous "Sun Cycle," and 2013 marked the beginning of a new "Sun Cycle." This was later distorted into the absurd claim that "2012 is the end of the world as predicted by the Mayans." Many people today speculate that the slow development of Mayan civilization was related to their use of the base-20 system. For computers, binary is the easiest to implement in physical devices, because high voltage can represent 1 and low voltage can represent 0. Not all programmers need to be familiar with binary or conversions between decimal, binary, octal, and hexadecimal — most of the time we can write programs without knowing these details. However, we must know that computers use binary counting, and regardless of the type of data, it exists in binary form in computer memory.

> **Note**: For information about the binary counting system and how to convert between different number bases, you can refer to books titled "Introduction to Computing" or "Computer Culture" — they all cover this topic. We won't elaborate further here; interested readers can study this on their own.

### Variables and Types

To save data in a computer's memory, we first need to talk about the concept of variables. In programming languages, **a variable is a carrier of data** — simply put, it is a piece of memory space used to store data, and **the value of a variable can be read and modified**, which is the foundation of all operations and control. Computers can process many types of data. The most common is numerical data, but besides numbers there are text, images, audio, video, and many other data types. Although all data exists in binary form in the computer, we can use different types of variables to represent different data types. Python comes with several built-in data types and also allows us to define new data types, which we will cover later. Let's first learn about some of the most commonly used data types in Python.

1. Integer (`int`): Python can handle integers of arbitrary size and supports binary (e.g., `0b100`, which is 4 in decimal), octal (e.g., `0o100`, which is 64 in decimal), decimal (`100`), and hexadecimal (e.g., `0x100`, which is 256 in decimal) representations. Run the following code and see what it outputs.

    ```python
    print(0b100)  # Binary integer
    print(0o100)  # Octal integer
    print(100)    # Decimal integer
    print(0x100)  # Hexadecimal integer
    ```

2. Float (`float`): Floats are decimal numbers. They are called floating-point numbers because when expressed in scientific notation, the position of the decimal point can vary. Floats support both standard notation (e.g., `123.456`) and scientific notation (e.g., `1.23456e2`, representing $\small{1.23456 \times 10^{2}}$). Run the following code and see what it outputs.

    ```python
    print(123.456)    # Standard notation
    print(1.23456e2)  # Scientific notation
    ```

3. String (`str`): A string is any text wrapped in single or double quotes, such as `'hello'` and `"hello"`.

4. Boolean (`bool`): The boolean type has only two values, `True` and `False` — either `True` or `False`. It can be used to represent "yes" and "no" in the real world, "true" and "false" in propositions, "good" and "bad" in conditions, "high" and "low" in levels, and so on. If a variable can only have two states, we can use the boolean type.

### Variable Naming

Each variable needs a name, just like each person has their own name. In Python, variable naming must follow these rules and conventions:

- Rules:
  - Rule 1: Variable names consist of **letters**, **digits**, and **underscores**, and cannot start with a digit. Note that "letters" here refers to Unicode characters. Unicode, also known as the Universal Character Set, encompasses most of the world's writing systems, which means Chinese characters, Japanese characters, Greek letters, etc. can all be used as characters in variable names, but special characters like `!`, `@`, `#`, etc. cannot appear in variable names. We strongly recommend treating "letters" here as meaning **use only English letters whenever possible**.
  - Rule 2: Python is a **case-sensitive** programming language, which simply means that uppercase `A` and lowercase `a` are two different variables. This is not really a rule, but something to be aware of.
  - Rule 3: Variable names **should not conflict with Python keywords** and should **try to avoid Python reserved words**. Keywords here refer to words with special meaning in Python programs (such as `is`, `if`, `else`, `for`, `while`, `True`, `False`, etc.), while reserved words mainly refer to names of Python built-in functions, built-in modules, etc. (such as `int`, `print`, `input`, `str`, `math`, `os`, etc.).
- Conventions:
  - Convention 1: Variable names typically use **lowercase English letters** with **multiple words connected by underscores**.
  - Convention 2: Protected variables start with a single underscore.
  - Convention 3: Private variables start with two underscores.

You don't need to worry about conventions 2 and 3 for now — they will make sense as we progress. Of course, as a professional programmer, it is also very important to give variables **meaningful names** — this demonstrates professional quality, and many development job interviews place great emphasis on this.

### Using Variables

Let's use examples to illustrate variable types and their usage.


In Python, you can use the `type` function to check the type of a variable. The concept of a function in programming is very similar to the concept of a function in mathematics. Mathematical functions should be familiar to everyone — they include a function name, independent variables, and dependent variables. If you don't understand the concept of functions yet, don't worry — we will cover function definition and usage in detail in later lessons.

```python
"""
Using the type function to check variable types

Version: 1.0
Author: Luo Hao
"""
a = 100
b = 123.45
c = 'hello, world'
d = True
print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'bool'>
```

You can change the type of a variable using Python's built-in functions. Here are some commonly used functions related to variable types:

- `int()`: Converts a number or string to an integer, with an optional base parameter.
- `float()`: Converts a string (when possible) to a float.
- `str()`: Converts the specified object to a string, with an optional encoding parameter.
- `chr()`: Converts an integer (character code) to the corresponding (single-character) string.
- `ord()`: Converts a (single-character) string to the corresponding integer (character code).

The following example demonstrates type conversion operations in Python.

```python
"""
Variable type conversion operations

Version: 1.0
Author: Luo Hao
"""
a = 100
b = 123.45
c = '123'
d = '100'
e = '123.45'
f = 'hello, world'
g = True
print(float(a))         # int 100 to float, outputs 100.0
print(int(b))           # float 123.45 to int, outputs 123
print(int(c))           # str '123' to int, outputs 123
print(int(c, base=16))  # str '123' as hexadecimal to int, outputs 291
print(int(d, base=2))   # str '100' as binary to int, outputs 4
print(float(e))         # str '123.45' to float, outputs 123.45
print(bool(f))          # str 'hello, world' to bool, outputs True
print(int(g))           # bool True to int, outputs 1
print(chr(a))           # int 100 to str, outputs 'd'
print(ord('d'))         # str 'd' to int, outputs 100
```

> **Note**: When converting `str` to `int`, you can specify the `base` parameter to indicate the number base, treating the string as an integer in the specified base for conversion. When converting `str` to `bool`, as long as the string has content (i.e., it is not `''` or `""`), the corresponding boolean value is `True`. When converting `bool` to `int`, `True` becomes `1` and `False` becomes `0`. In both the ASCII and Unicode character sets, the character `'d'` corresponds to the code `100`.
