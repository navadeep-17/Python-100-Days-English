## Operators in Python

Python supports a wide variety of operators. The table below lists the operators in Python from highest to lowest priority. With variables and operators, we can construct all kinds of expressions to solve real-world problems. In computer science, **an expression is a syntactic entity in a computer program that consists of one or more constants, variables, functions, and operators combined together, and the programming language can interpret and evaluate it to produce another value**. It's fine if you don't understand this sentence, but you must know that constructing expressions is extremely important in any programming language.

| Operator | Description |
| ------------------------------------------------------------ | ------------------------------ |
| `[]`, `[:]` | Indexing, Slicing |
| `**` | Exponentiation |
| `~`, `+`, `-` | Bitwise NOT, Positive, Negative |
| `*`, `/`, `%`, `//` | Multiply, Divide, Modulo, Floor Division |
| `+`, `-` | Addition, Subtraction |
| `>>`, `<<` | Right Shift, Left Shift |
| `&` | Bitwise AND |
| `^`, `\|` | Bitwise XOR, Bitwise OR |
| `<=`, `<`, `>`, `>=` | Less Than or Equal, Less Than, Greater Than, Greater Than or Equal |
| `==`, `!=` | Equal, Not Equal |
| `is`, `is not` | Identity Operators |
| `in`, `not in` | Membership Operators |
| `not`, `or`, `and` | Logical Operators |
| `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `//=`, `**=`, `&=`, `\|=`, `^=`, `>>=`, `<<=` | Assignment Operators |

> **Note**: Priority means that when an expression contains multiple operators, the order in which they are executed matters. When writing code, if you're unsure about operator priority in an expression, you can use parentheses to ensure the desired execution order.

### Arithmetic Operators

Python has a rich set of arithmetic operators. In addition to the familiar addition, subtraction, multiplication, and division, there are also floor division, modulo (remainder), and exponentiation operators. The following example demonstrates how arithmetic operators work.

```python
"""
Arithmetic Operators

Version: 1.0
Author: Luo Hao
"""
print(321 + 12)     # Addition, outputs 333
print(321 - 12)     # Subtraction, outputs 309
print(321 * 12)     # Multiplication, outputs 3852
print(321 / 12)     # Division, outputs 26.75
print(321 // 12)    # Floor division, outputs 26
print(321 % 12)     # Modulo, outputs 9
print(321 ** 12)    # Exponentiation, outputs 1196906950228928915420617322241
```

Arithmetic operations follow the "multiplication and division before addition and subtraction" rule, which is the same as what you learned in math class — multiplication and division have higher priority than addition and subtraction. If there is exponentiation, it has higher priority than multiplication and division. If you want to change the order of arithmetic operations, you can use parentheses (typed in English input mode) — expressions inside parentheses are evaluated first, as shown in the example below.

```python
"""
Arithmetic Operator Priority

Version: 1.0
Author: Luo Hao
"""
print(2 + 3 * 5)           # 17
print((2 + 3) * 5)         # 25
print((2 + 3) * 5 ** 2)    # 125
print(((2 + 3) * 5) ** 2)  # 625
```

### Assignment Operators

The assignment operator is probably the most commonly used operator. Its purpose is to assign the value on the right to the variable on the left. Assignment operators can be combined with arithmetic operators to form compound assignment operators. For example, `a += b` is equivalent to `a = a + b`, and `a *= a + 2` is equivalent to `a = a * (a + 2)`. The following example demonstrates the use of assignment and compound assignment operators.

```python
"""
Assignment and Compound Assignment Operators

Version: 1.0
Author: Luo Hao
"""
a = 10
b = 3
a += b        # Equivalent to: a = a + b
a *= a + 2    # Equivalent to: a = a * (a + 2)
print(a)      # Try to figure out what this outputs
```

An assignment expression itself does not produce a value, which means if you put an assignment expression inside a `print` function to try to output the expression's value, it will produce a syntax error. To solve this problem, Python 3.8 introduced a new assignment operator `:=`, called the walrus operator — can you guess why it's called that? The walrus operator also assigns the value on its right to the variable on the left, but unlike the regular assignment operator, the value on the right side also becomes the value of the entire expression. See the code below to understand.

```python
"""
Walrus Operator

Version: 1.0
Author: Luo Hao
"""
# SyntaxError: invalid syntax
# print((a = 10))
# Walrus operator
print((a := 10))  # 10
print(a)          # 10
```

> **Tip**: If line 8 of the code above is not commented out, running the code will show the error `SyntaxError: invalid syntax`. Note that we added parentheses around `a = 10` in that line. If you accidentally write `print(a = 10)` instead, you'll see the error `TypeError: 'a' is an invalid keyword argument for print()` — when we cover functions later, you'll understand what this error message means.

### Comparison Operators and Logical Operators

Comparison operators, also called relational operators, include `==`, `!=`, `<`, `>`, `<=`, `>=` — these should be self-explanatory. Note that equality comparison uses `==` (two equal signs), because `=` is the assignment operator we just discussed. Inequality uses `!=`, which differs from the $\small{\neq}$ used in math textbooks. Python 2 once used `<>` for inequality, but using `<>` in Python 3 will cause a `SyntaxError`. Comparison operators produce boolean values — either `True` or `False`.

Logical operators include `and`, `or`, and `not`. `and` literally means "and," so the `and` operator connects two boolean values or expressions that produce boolean values. If both sides are `True`, the result is `True`; if either side is `False`, the result is `False`. Of course, if the left side of `and` is `False`, regardless of the right side, the result is always `False` — in this case, the right side is skipped (this is called short-circuit evaluation; if the right side is an expression, it won't be evaluated). `or` literally means "or," so the `or` operator also connects two boolean values or expressions. If either side is `True`, the result is `True`. `or` also supports short-circuit evaluation: when the left side is `True`, the right side is skipped. The `not` operator can be followed by a boolean value; if the value after `not` is `True`, the result is `False`; if it's `False`, the result is `True`.

```python
"""
Using comparison and logical operators

Version: 1.0
Author: Luo Hao
"""
flag0 = 1 == 1
flag1 = 3 > 2
flag2 = 2 < 1
flag3 = flag1 and flag2
flag4 = flag1 or flag2
flag5 = not flag0
print('flag0 =', flag0)     # flag0 = True
print('flag1 =', flag1)     # flag1 = True
print('flag2 =', flag2)     # flag2 = False
print('flag3 =', flag3)     # flag3 = False
print('flag4 =', flag4)     # flag4 = True
print('flag5 =', flag5)     # flag5 = False
print(flag1 and not flag2)  # True
print(1 > 2 or 2 == 3)      # False
```

> **Note**: Comparison operators have higher priority than assignment operators, so `flag0 = 1 == 1` above first evaluates `1 == 1` to produce `True`, then assigns this value to the variable `flag0`. The `print` function can output multiple values separated by `,`, with the output separated by spaces by default.

### Applying Operators and Expressions

#### Example 1: Converting Fahrenheit to Celsius

> **Requirement**: Input a Fahrenheit temperature and convert it to Celsius. The conversion formula is: $\small{C = (F - 32) / 1.8}$.

```python
"""
Convert Fahrenheit to Celsius

Version: 1.0
Author: Luo Hao
"""
f = float(input('Enter Fahrenheit temperature: '))
c = (f - 32) / 1.8
print('%.1f Fahrenheit = %.1f Celsius' % (f, c))
```

> **Note**: The `input` function in the code above reads user input from the keyboard. Since all input is a string, if we want to process it as a floating-point number for subsequent calculations, we can use the type conversion method from the previous lesson — the `float` function converts `str` to `float`.

In the code above, we formatted the output of the `print` function. The output string contains two `%.1f` placeholders, which will be replaced by the two `float` values in `(f, c)` after the `%`, with one decimal place preserved. If the string contains a `%d` placeholder, it will be replaced by an `int` value; if it contains a `%s` placeholder, it will be replaced by a `str` value.

In addition to the formatting method above, Python also provides another way to format output. We provide a string with placeholders, and the `f` before the string indicates that it needs to be formatted. `{f:.1f}` and `{c:.1f}` can be seen as `{f}` and `{c}`, meaning the values of variables `f` and `c` will replace these placeholders at output time. The `:.1f` suffix indicates it's a float with one decimal place.

```python
"""
Convert Fahrenheit to Celsius

Version: 1.1
Author: Luo Hao
"""
f = float(input('Enter Fahrenheit temperature: '))
c = (f - 32) / 1.8
print(f'{f:.1f} Fahrenheit = {c:.1f} Celsius')
```

#### Example 2: Calculating the Circumference and Area of a Circle

> **Requirement**: Input the radius ($\small{r}$) of a circle, and calculate its circumference ($\small{2 \pi r}$) and area ($\small{\pi r^{2}}$).

```python
"""
Calculate circumference and area given the radius

Version: 1.0
Author: Luo Hao
"""
radius = float(input('Enter the radius: '))
perimeter = 2 * 3.1416 * radius
area = 3.1416 * radius * radius
print('Circumference: %.2f' % perimeter)
print('Area: %.2f' % area)
```

Python has a built-in module called `math` that defines a variable named `pi` whose value is the mathematical constant pi. If we want to use Python's built-in `pi`, we can modify the code above slightly.

```python
"""
Calculate circumference and area given the radius

Version: 1.1
Author: Luo Hao
"""
import math

radius = float(input('Enter the radius: '))
perimeter = 2 * math.pi * radius
area = math.pi * radius ** 2
print(f'Circumference: {perimeter:.2f}')
print(f'Area: {area:.2f}')
```

> **Note**: The `import math` statement in the code above imports the `math` module. After importing, you can use `math.pi` to get the value of pi.

There is actually another way to format output, which was added as a new feature in Python 3.8. See the code below to understand.

```python
"""
Calculate circumference and area given the radius

Version: 1.2
Author: Luo Hao
"""
import math

radius = float(input('Enter the radius: '))  # Input: 5.5
perimeter = 2 * math.pi * radius
area = math.pi * radius ** 2
print(f'{perimeter = :.2f}')  # Output: perimeter = 34.56
print(f'{area = :.2f}')       # Output: area = 95.03
```

> **Note**: If variable `a` has the value `9.87`, then the string `f'{a = }'` evaluates to `a = 9.87`; and the string `f'{a = :.1f}'` evaluates to `a = 9.9`. This formatting style outputs both the variable name and its value.

#### Example 3: Determining a Leap Year

Requirement: Input a year after 1582 and determine whether it is a leap year.

```python
"""
Input a year, output True for leap year, False for common year

Version: 1.0
Author: Luo Hao
"""
year = int(input('Enter a year: '))
is_leap = year % 4 == 0 and year % 100 != 0 or year % 400 == 0
print(f'{is_leap = }')
```

> **Note**: For the Gregorian calendar (the calendar we use today), the rules for determining a leap year are: 1. A year not divisible by 4 is a common year; 2. A year divisible by 4 but not by 100 is a leap year; 3. A year divisible by 400 is a leap year. The Gregorian calendar was introduced by Pope Gregory XIII in October 1582 as a modification and replacement of the Julian calendar, so keep this in mind when entering years. The code above uses `%` to check whether `year` is a multiple of `4`, `100`, or `400`, then uses `and` and `or` operators to combine the three conditions — the first two conditions must both be satisfied, while the third condition only needs to satisfy one of the combinations.
