## Branching Structures

So far, all the Python programs we have written execute statements one by one from top to bottom. This kind of code structure is called a sequential structure. However, sequential structures alone cannot solve all problems. For example, if we are designing a game where the condition to pass the first level is for the player to score 1000 points, then after completing the first level, we need to decide based on the player's score whether to proceed to the second level or tell the player "Game Over." In this scenario, our code will produce two branches, and only one will be executed. There are many similar scenarios, and we call this kind of structure a "branching structure" or "selection structure." Take a minute to think about it, and you should be able to come up with at least 5 similar examples. Give it a try!

### Constructing Branching Structures with if and else

In Python, the most common way to construct branching structures is with the three keywords `if`, `elif`, and `else`. A **keyword** is a word that has special meaning in a programming language, so obviously you cannot use it as a variable name. Of course, we don't always use all three keywords every time we construct a branching structure. Let's illustrate with examples. For instance, let's write a Body Mass Index (BMI) calculator. BMI, also known as body mass index, is an internationally used metric for measuring body weight status and health. The formula is shown below. Generally, $\small{18.5 \le BMI < 24}$ is considered the normal range, $\small{BMI < 18.5}$ indicates underweight, $\small{BMI \ge 24}$ indicates overweight, and $\small{BMI \ge 27}$ falls into the obesity category.

$$
BMI = \frac{weight}{height^{2}}
$$

> **Note**: In the formula above, weight is in kilograms (kg) and height is in meters (m).

```python
"""
BMI Calculator

Version: 1.0
Author: Luo Hao
"""
height = float(input('Height (cm): '))
weight = float(input('Weight (kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('You are in great shape!')
```

> **Tip**: The `if` statement ends with a `:`, which is a colon entered using the English input method. Special characters such as `'`, `"`, `=`, `(`, `)` in the program are all entered using the English input method, which we have reminded you about before. Many beginners often overlook this point, and when they run the code, they see a lot of error messages. Of course, carefully reading the error messages makes it easy to find out what went wrong, but it is **strongly recommended** that you **switch to the English input method** when writing code, as this can avoid many unnecessary troubles.

In the code above, after calculating and outputting the BMI, we added a branching structure. If the condition $\small{18.5 \le BMI < 24}$ is met, the program will output "You are in great shape!", but if the condition is not met, this output will not appear. This is what we mentioned earlier -- code can have different execution paths, and some code may not necessarily be executed. After the `if` keyword, we provided an expression `18.5 <= bmi < 24`. As we mentioned before, relational operations produce boolean values. If the boolean value after `if` is `True`, then the `print('You are in great shape!')` statement below the `if` statement, which is indented by four spaces, will be executed. Let's input a few sets of data and run the code above, as shown below.

First set of input:

```

Weight (kg): 68
bmi = 22.2
You are in great shape!
```

Second set of input:

```

Weight (kg): 95
bmi = 31.0
```

Third set of input:

```
Height (cm): 175
Weight (kg): 50
bmi = 16.3
```

Only the first set of input produced a BMI within the range of 18.5 to 24, which triggered the `if` condition and output "You are in great shape!" It should be noted that, unlike programming languages such as C, C++, and Java, Python does not use curly braces to construct code blocks but instead **uses indentation to represent the hierarchical structure of code**. If multiple statements need to be executed when the `if` condition is true, just keep them at the same indentation level. In other words, if several consecutive lines of statements have the same indentation, they belong to the same **code block**, which is essentially an execution unit. Indentation can use any number of spaces, but **4 spaces is the convention**. It is strongly recommended that you **do not use the Tab key to indent code**. If you are already used to doing so, you can set your code editor to automatically convert 1 Tab into 4 spaces, a feature supported by many code editors. PyCharm uses this setting by default. Also, in programming languages like C, C++, and Java, `18.5 <= bmi < 24` has to be written as two conditions `bmi >= 18.5` and `bmi < 24`, connected with the AND operator. Python can do this too -- for example, the `if` statement above could also be written as `if bmi >= 18.5 and bmi < 24:` -- but there's no need. Isn't `if 18.5 <= bmi < 24:` much nicer? Below is the same thing done in Java code. Don't worry if you can't read Java code; just feel the difference between it and Python syntax.

```java
import java.util.Scanner;

class Test {

    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in)) {
            System.out.print("Height (cm): ");
            double height = sc.nextDouble();
            System.out.print("Weight (kg): ");
            double weight = sc.nextDouble();
            double bmi = weight / Math.pow(height / 100, 2);
            System.out.printf("bmi = %.1f\n", bmi);
            if (bmi >= 18.5 && bmi < 24) {
                System.out.println("You are in great shape!");
            }
        }
    }
}
```

> **Note**: The Java code above corresponds to BMI Calculator version 1.0. It's not without reason that many people prefer the Python language -- it usually solves the same problem with less code.

Next, let's slightly modify the code above so that when the BMI does not satisfy $\small{18.5 \le BMI < 24}$, we also provide an informative message. We can add an `else` block after the `if` block, which will execute when the condition given by the `if` statement is not met, as shown below. Obviously, only one of `print('You are in great shape!')` under `if` and `print('Your body shape is not up to standard!')` under `else` will be executed.

```python

    print('You are in great shape!')
else:
    print('Your body shape is not up to standard!')
```

### Constructing Branching Structures with match and case

Python 3.10 introduced a new way to construct branching structures. By using the `match` and `case` keywords, we can easily construct multi-branch structures. When the official Python documentation introduced this new syntax, it gave an example of HTTP response status code identification (outputting the corresponding description based on the HTTP response status), which is quite interesting. If you don't know what HTTP response status codes are, you can check out the [documentation](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Status) on MDN. Let's slightly modify the example from the official documentation to explain this syntax. First, let's look at the code implemented with the `if-else` structure.

```python
status_code = int(input('Response status code: '))
if status_code == 400:
    description = 'Bad Request'
elif status_code == 401:
    description = 'Unauthorized'
elif status_code == 403:
    description = 'Forbidden'
elif status_code == 404:
    description = 'Not Found'
elif status_code == 405:
    description = 'Method Not Allowed'
elif status_code == 418:
    description = 'I am a teapot'
elif status_code == 429:
    description = 'Too many requests'
else:
    description = 'Unknown status Code'
print('Status code description:', description)
```

Output:

```
Response status code: 403
Status code description: Forbidden
```

Below is the code implemented using the `match-case` syntax. Although the functionality is exactly the same, the code appears simpler and more elegant.

```python
status_code = int(input('Response status code: '))
match status_code:
    case 400: description = 'Bad Request'
    case 401: description = 'Unauthorized'
    case 403: description = 'Forbidden'
    case 404: description = 'Not Found'
    case 405: description = 'Method Not Allowed'
    case 418: description = 'I am a teapot'
    case 429: description = 'Too many requests'
    case _: description = 'Unknown Status Code'
print('Status code description:', description)
```

> **Note**: The `case` statement with `_` acts as a wildcard in the code. If none of the preceding branches match, the code will fall through to `case _`. The `case _` is optional and not every branching structure needs a wildcard option. If `case _` appears in a branch structure, it can only be placed at the very end. If there are other branches after it, those branches will be unreachable.

Of course, the `match-case` syntax has many advanced features. One of them is the merge pattern, which we can introduce here. For example, if we want to group response status codes `401`, `403`, and `404` into one branch, `400` and `405` into another branch, and keep the rest unchanged, the code can be written as follows.

```python
status_code = int(input('Response status code: '))
match status_code:
    case 400 | 405: description = 'Invalid Request'
    case 401 | 403 | 404: description = 'Not Allowed'
    case 418: description = 'I am a teapot'
    case 429: description = 'Too many requests'
    case _: description = 'Unknown Status Code'
print('Status code description:', description)
```

Output:

```
Response status code: 403
Status code description: Not Allowed
```

### Applications of Branching Structures

#### Example 1: Evaluating a Piecewise Function

Given the following piecewise function, input `x` and compute `y`.

$$
y = \begin{cases} 3x - 5, & (x \gt 1) \\\\ x + 2, & (-1 \le x \le 1) \\\\ 5x + 3, & (x \lt -1) \end{cases}
$$

```python
"""
Piecewise Function Evaluation

Version: 1.0
Author: Luo Hao
"""
x = float(input('x = '))
if x > 1:
    y = 3 * x - 5
elif x >= -1:
    y = x + 2
else:
    y = 5 * x + 3
print(f'{y = }')
```

Depending on actual development needs, branching structures can be nested, meaning that within the `if`, `elif`, or `else` code blocks of a branching structure, you can introduce another branching structure. For example, if the `if` condition being true means the player has passed the level, but after passing, you still need to rate the player's performance based on the number of treasures or items collected (e.g., awarding one, two, or three stars), then you need to construct a new branching structure inside the `if` block. Similarly, you can construct new branches in `elif` and `else`, which we call nested branching structures. Following this approach, the piecewise function evaluation above can also be implemented with the following code.

```python
"""
Piecewise Function Evaluation

Version: 1.1
Author: Luo Hao
"""
x = float(input('x = '))
if x > 1:
    y = 3 * x - 5
else:
    if x >= -1:
        y = x + 2
    else:
        y = 5 * x + 3
print(f'{y = }')
```

> **Note**: You can judge for yourself which of the two approaches above is better. In "[**The Zen of Python**](https://zhuanlan.zhihu.com/p/111843067)," there is a saying: "**Flat is better than nested**." The reason "flat" code is considered better is that deeply nested code severely impacts readability. Therefore, I personally recommend the first approach.

#### Example 2: Converting Percentage Scores to Letter Grades

Requirements: If the input score is 90 or above, output `A`; if the score is between 80 and 90 (exclusive of 90), output `B`; if the score is between 70 and 80 (exclusive of 80), output `C`; if the score is between 60 and 70 (exclusive of 70), output `D`; if the score is below 60, output `E`.

```python
"""
Convert Percentage Score to Letter Grade

Version: 1.0
Author: Luo Hao
"""
score = float(input('Please enter the score: '))
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
elif score >= 70:
    grade = 'C'
elif score >= 60:
    grade = 'D'
else:
    grade = 'E'
print(f'{grade = }')
```
#### Example 3: Computing the Perimeter and Area of a Triangle

Requirements: Input the lengths of three sides. If they can form a triangle, compute the perimeter and area; otherwise, display a message saying "Cannot form a triangle."

```python
"""
Compute the Perimeter and Area of a Triangle

Version: 1.0
Author: Luo Hao
"""
a = float(input('a = '))
b = float(input('b = '))
c = float(input('c = '))
if a + b > c and a + c > b and b + c > a:
    perimeter = a + b + c
    print(f'Perimeter: {perimeter}')
    s = perimeter / 2
    area = (s * (s - a) * (s - b) * (s - c)) ** 0.5
    print(f'Area: {area}')
else:
    print('Cannot form a triangle')
```
> **Note:** The `if` condition above checks that the sum of any two sides is greater than the third side, which is the necessary condition for forming a triangle. When this condition is true, we calculate and output the perimeter and area, so there are five statements below `if` that all have the same indentation. They form a single unit and will all be executed when the `if` condition is true -- this is the concept of a code block that we mentioned earlier. Also, the formula used above to calculate the area of a triangle is called Heron's formula. Given a triangle with sides of length $\small{a}$, $\small{b}$, and $\small{c}$, the area $\small{A}$ can be calculated using the formula $\small{A = \sqrt{s(s-a)(s-b)(s-c)}}$, where $s=\frac{a + b + c}{2}$ represents the semi-perimeter.
