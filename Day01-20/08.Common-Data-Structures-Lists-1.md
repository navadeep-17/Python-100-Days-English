## Common Data Structures: Lists (Part 1)

Before we begin this lesson, let's give you a programming task: roll a die 6000 times and count the number of occurrences of each face value. This task should be quite simple for you. We can simulate rolling a die using uniformly distributed random numbers from 1 to 6, then use 6 variables to record the number of occurrences of each face value. With what we've learned so far, you should be able to write the following code fairly smoothly.

```python
"""
Roll a die 6000 times and count the occurrences of each face value

Author: Luo Hao
Version: 1.0
"""
import random

f1 = 0
f2 = 0
f3 = 0
f4 = 0
f5 = 0
f6 = 0
for _ in range(6000):
    face = random.randrange(1, 7)
    if face == 1:
        f1 += 1
    elif face == 2:
        f2 += 1
    elif face == 3:
        f3 += 1
    elif face == 4:
        f4 += 1
    elif face == 5:
        f5 += 1
    else:
        f6 += 1
print(f'Face 1 appeared {f1} times')
print(f'Face 2 appeared {f2} times')
print(f'Face 3 appeared {f3} times')
print(f'Face 4 appeared {f4} times')
print(f'Face 5 appeared {f5} times')
print(f'Face 6 appeared {f6} times')
```

How "ugly" the code above is should go without saying. What's even worse is that if we need to roll two or more dice and count the occurrences of each point total, we would need to define even more variables and write even more branching structures -- just thinking about it is nauseating. At this point, you're probably wondering: Is there a way to store multiple data values in a single variable? Is there a way to operate on multiple data values with unified code? The answer is yes. In Python, we can use container-type variables to store and manipulate multiple data values. First, let's introduce a new data type called a list (`list`).

### Creating Lists

In Python, **a list is a data sequence consisting of a series of elements arranged in a specific order**, which means that if we define a variable of the list type, **it can store multiple data values**. In Python, you can use `[]` literal syntax to define a list, with multiple elements separated by commas, as shown below.

```python
items1 = [35, 12, 99, 68, 55, 35, 87]
items2 = ['Python', 'Java', 'Go', 'Kotlin']
items3 = [100, 12.3, 'Python', True]
print(items1)  # [35, 12, 99, 68, 55, 35, 87]
print(items2)  # ['Python', 'Java', 'Go', 'Kotlin']
print(items3)  # [100, 12.3, 'Python', True]
```

> **Note**: A list can contain duplicate elements, such as `35` in `items1`; a list can contain elements of different types, such as `items3` which has `int`, `float`, `str`, and `bool` type elements. However, we generally do not recommend putting different types of elements in the same list, mainly because it would be extremely inconvenient to work with.

We can use the `type` function to check the type of a variable. If you're curious, you can check the type of `items1` above. Since lists can hold multiple elements, they are a container-type data type, so when naming list-type variables, we typically use plural forms of words.

In addition, you can convert other sequences into lists using Python's built-in `list` function. Strictly speaking, `list` is not an ordinary function -- it is a constructor for creating list objects. We will explain the concepts of objects and constructors in later lessons.

```python
items4 = list(range(1, 10))
items5 = list('hello')
print(items4)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
print(items5)  # ['h', 'e', 'l', 'l', 'o']
```

> **Note**: `range(1, 10)` produces an integer sequence from `1` to `9`. When passed to the `list` constructor, it creates a list consisting of integers from `1` to `9`. A string is a sequence of characters. The `list('hello')` above uses the characters of the string `hello` as list elements to create a list object.

### List Operations

We can use the `+` operator to concatenate two lists. The concatenation operation joins the elements of two lists into a single list, as shown below.

```python
items5 = [35, 12, 99, 45, 66]
items6 = [45, 58, 29]
items7 = ['Python', 'Java', 'JavaScript']
print(items5 + items6)  # [35, 12, 99, 45, 66, 45, 58, 29]
print(items6 + items7)  # [45, 58, 29, 'Python', 'Java', 'JavaScript']
items5 += items6
print(items5)  # [35, 12, 99, 45, 66, 45, 58, 29]
```

We can use the `*` operator to repeat a list. The `*` operator repeats the list elements a specified number of times. Adding two more lines to the code above:

```python
print(items6 * 3)  # [45, 58, 29, 45, 58, 29, 45, 58, 29]
print(items7 * 2)  # ['Python', 'Java', 'JavaScript', 'Python', 'Java', 'JavaScript']
```

We can use the `in` or `not in` operators to check whether an element is in a list. Adding two more lines to the code above:

```python
print(29 in items6)  # True
print(99 in items6)  # False
print('C++' not in items7)     # True
print('Python' not in items7)  # False
```

Since a list has multiple elements and they are arranged in a specific order, when we want to operate on a specific element, we can use the `[]` operator to access it by specifying its position within `[]`. This operation is called indexing. Note that the element position in `[]` can be an integer from `0` to `N - 1`, or from `-1` to `-N`, known as forward indexing and reverse indexing respectively, where `N` represents the number of elements in the list. With forward indexing, `[0]` accesses the first element and `[N - 1]` accesses the last; with reverse indexing, `[-1]` accesses the last element and `[-N]` accesses the first, as shown below.

```python
items8 = ['apple', 'waxberry', 'pitaya', 'peach', 'watermelon']
print(items8[0])   # apple
print(items8[2])   # pitaya
print(items8[4])   # watermelon
items8[2] = 'durian'
print(items8)      # ['apple', 'waxberry', 'durian', 'peach', 'watermelon']
print(items8[-5])  # 'apple'
print(items8[-4])  # 'waxberry'
print(items8[-1])  # watermelon
items8[-4] = 'strawberry'
print(items8)      # ['apple', 'strawberry', 'durian', 'peach', 'watermelon']
```

When using index operations, be careful to avoid index out-of-range errors. For the `items8` above, accessing `items8[5]` or `items8[-6]` would raise an `IndexError`, crashing the program with the message: *list index out of range*. Because for a list with only five elements, the valid forward indices are `0` to `4`, and the valid reverse indices are `-1` to `-5`.

If you want to access multiple elements at once, you can use slicing. Slicing takes the form `[start:end:stride]`, where `start` is the starting position, `end` is the ending position (the element at the ending position is not included), and `stride` is the step size, meaning the position increment. For example, the first element accessed is at position `start`, and the second is at `start + stride`, as long as `start + stride` is less than `end`. Let's add slicing operations to the code above.

```python
print(items8[1:3:1])     # ['strawberry', 'durian']
print(items8[0:3:1])     # ['apple', 'strawberry', 'durian']
print(items8[0:5:2])     # ['apple', 'durian', 'watermelon']
print(items8[-4:-2:1])   # ['strawberry', 'durian']
print(items8[-2:-6:-1])  # ['peach', 'durian', 'strawberry', 'apple']
```

> **Reminder**: Take a look at the last line of code above and think about how slicing works when the stride is negative.

If the `start` value equals `0`, it can be omitted in the slice operator; if the `end` value equals `N` (the number of list elements), it can be omitted; if the `stride` value equals `1`, it can also be omitted. So the code below has exactly the same effect as the code above.

```python
print(items8[1:3])     # ['strawberry', 'durian']
print(items8[:3:1])    # ['apple', 'strawberry', 'durian']
print(items8[::2])     # ['apple', 'durian', 'watermelon']
print(items8[-4:-2])   # ['strawberry', 'durian']
print(items8[-2::-1])  # ['peach', 'durian', 'strawberry', 'apple']
```

In fact, we can also modify list elements through slicing. Add one more line to the code above and see the output.

```python
items8[1:3] = ['x', 'o']
print(items8)  # ['apple', 'x', 'o', 'peach', 'watermelon']
```

Two lists can also be compared using relational operators -- we can check if two lists are equal or compare their sizes, as shown below.

```python
nums1 = [1, 2, 3, 4]
nums2 = list(range(1, 5))
nums3 = [3, 2, 1]
print(nums1 == nums2)  # True
print(nums1 != nums2)  # False
print(nums1 <= nums3)  # True
print(nums2 >= nums3)  # False
```

> **Note**: `nums1` and `nums2` above have identical corresponding elements, so the `==` operation returns `True`. For the comparison of `nums2` and `nums3`, since the first element of `nums2` (`1`) is less than the first element of `nums3` (`3`), `nums2 >= nums3` returns `False`. Relational operations on lists are not commonly used in practice, so if you don't fully understand them, you can skip ahead without worrying.

### Iterating Over Elements

If you want to iterate through each element in a list, you can use a `for-in` loop. There are two approaches.

Approach 1: Iterate over list elements using index operations within a loop.

```python
languages = ['Python', 'Java', 'C++', 'Kotlin']
for index in range(len(languages)):
    print(languages[index])
```

Output:

```
Python
Java
C++
Kotlin
```

> **Note**: The `len` function above gets the number of elements `N` in the list, and `range(N)` constructs a range from `0` to `N-1`, which can serve as the indices for the list elements.

Approach 2: Loop directly over the list, where the loop variable represents each list element.

```python
languages = ['Python', 'Java', 'C++', 'Kotlin']
for language in languages:
    print(language)
```

Output:

```
Python
Java
C++
Kotlin
```

### Summary

Now that we've covered lists, we can use our knowledge to refactor the "roll a die and count occurrences" code from the beginning.

```python
"""
Roll a die 6000 times and count the occurrences of each face value

Author: Luo Hao
Version: 1.1
"""
import random

counters = [0] * 6
# Simulate rolling the die and record the occurrences of each face value
for _ in range(6000):
    face = random.randrange(1, 7)
    counters[face - 1] += 1
# Output the number of occurrences of each face value
for face in range(1, 7):
    print(f'Face {face} appeared {counters[face - 1]} times')
```

In the code above, we use the six elements of the `counters` list to represent the number of occurrences of face values 1 through 6, with all six elements initially set to 0. Then, we simulate rolling the die using uniformly distributed random numbers from 1 to 6. If a 1 is rolled, `counters[0]` is incremented; if a 2 is rolled, `counters[1]` is incremented; and so on. As you can see, by using a list type combined with a loop structure, we can process data in bulk, making the refactored code much simpler and more elegant than the previous version.
