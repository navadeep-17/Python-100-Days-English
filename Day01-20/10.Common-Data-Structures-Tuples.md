## Common Data Structures: Tuples

In the previous two lessons, we covered Python lists, a container-type data type. With list variables, we can store multiple data values and use loops to perform batch operations on them. Of course, Python has other container-type data types. Next, we'll introduce another container-type data type called tuple.

### Tuple Definition and Operations

In Python, a tuple is also a sequence of multiple elements arranged in a specific order. The difference between tuples and lists is that **tuples are immutable types**, meaning that once a tuple variable is defined, its elements cannot be added, removed, or modified. Attempting to modify an element in a tuple will raise a `TypeError`, crashing the program. Tuples are usually defined using the literal syntax `(x, y, z)`. Tuple types support the same operators as lists. See the code below.

```python
# Define a 3-tuple
t1 = (35, 12, 98)
# Define a 4-tuple
t2 = ('Luo Hao', 45, True, 'Chengdu, Sichuan')

# Check the type of variables
print(type(t1))  # <class 'tuple'>
print(type(t2))  # <class 'tuple'>

# Check the number of elements in a tuple
print(len(t1))  # 3
print(len(t2))  # 4

# Indexing operations
print(t1[0])    # 35
print(t1[2])    # 98
print(t2[-1])   # Chengdu, Sichuan

# Slicing operations
print(t2[:2])   # ('Luo Hao', 45)
print(t2[::3])  # ('Luo Hao', 'Chengdu, Sichuan')

# Iterating over tuple elements
for elem in t1:
    print(elem)

# Membership operations
print(12 in t1)         # True
print(99 in t1)         # False
print('Hao' not in t2)  # True

# Concatenation
t3 = t1 + t2
print(t3)  # (35, 12, 98, 'Luo Hao', 45, True, 'Chengdu, Sichuan')

# Comparison operations
print(t1 == t3)            # False
print(t1 >= t3)            # False
print(t1 <= (35, 11, 99))  # False
```

A tuple with two elements is called a 2-tuple; one with five elements is called a 5-tuple. Note that `()` represents an empty tuple, but if a tuple has only one element, you need to add a comma. Otherwise, `()` is not tuple literal syntax but parentheses for changing operator precedence. So `('hello', )` and `(100, )` are 1-tuples, while `('hello')` and `(100)` are just a string and an integer. We can verify this with the code below.

```python
a = ()
print(type(a))  # <class 'tuple'>
b = ('hello')
print(type(b))  # <class 'str'>
c = (100)
print(type(c))  # <class 'int'>
d = ('hello', )
print(type(d))  # <class 'tuple'>
e = (100, )
print(type(e))  # <class 'tuple'>
```

### Packing and Unpacking

When we assign multiple comma-separated values to a single variable, they are packed into a tuple. When we assign a tuple to multiple variables, the tuple is unpacked into multiple values which are then assigned to the corresponding variables, as shown below.

```python
# Packing
a = 1, 10, 100
print(type(a))  # <class 'tuple'>
print(a)        # (1, 10, 100)
# Unpacking
i, j, k = a
print(i, j, k)  # 1 10 100
```

When unpacking, if the number of unpacked elements doesn't match the number of variables, a `ValueError` will be raised, with the message: `too many values to unpack` or `not enough values to unpack`.

```python
a = 1, 10, 100, 1000
# i, j, k = a             # ValueError: too many values to unpack (expected 3)
# i, j, k, l, m, n = a    # ValueError: not enough values to unpack (expected 6, got 4)
```

One way to handle having fewer variables than elements is to use star expressions. With a star expression, a variable can receive multiple values, as shown below. Two things to note: first, a variable modified with a star expression becomes a list with 0 or more elements; second, only one star expression can appear in the unpacking syntax.

```python
a = 1, 10, 100, 1000
i, j, *k = a
print(i, j, k)        # 1 10 [100, 1000]
i, *j, k = a
print(i, j, k)        # 1 [10, 100] 1000
*i, j, k = a
print(i, j, k)        # [1, 10] 100 1000
*i, j = a
print(i, j)           # [1, 10, 100] 1000
i, *j = a
print(i, j)           # 1 [10, 100, 1000]
i, j, k, *l = a
print(i, j, k, l)     # 1 10 100 [1000]
i, j, k, l, *m = a
print(i, j, k, l, m)  # 1 10 100 1000 []
```

It should be noted that unpacking syntax works for all sequences, meaning that lists, ranges constructed by the `range` function, and even strings can all use unpacking syntax. Try running the code below and see what happens.

```python
a, b, *c = range(1, 10)
print(a, b, c)
a, b, c = [1, 10, 100]
print(a, b, c)
a, *b, c = 'hello'
print(a, b, c)
```

### Swapping Variable Values

Swapping variable values is a common operation in programming. In many programming languages, swapping two variables requires an intermediate variable. Without one, you'd need to use somewhat obscure bitwise operations. In Python, swapping two variables `a` and `b` only requires the code below.

```python
a, b = b, a
```

Similarly, if you want to rotate three variables `a`, `b`, `c` -- assigning `b`'s value to `a`, `c`'s value to `b`, and `a`'s value to `c` -- you can do the same.

```python
a, b, c = b, c, a
```

Note that the operations above do not use packing and unpacking syntax. Python's bytecode instructions include `ROT_TWO` and `ROT_THREE` which directly implement these operations very efficiently. However, if more than three variables need their values rotated, there are no direct bytecode instructions available, and packing/unpacking must be used.

### Comparing Tuples and Lists

Here's a very worthwhile question to discuss: since Python already has the list type, why does it also need tuples? This might be a bit challenging for beginners, but let's put forth the argument and you can gradually appreciate it as you learn.

1. Tuples are immutable types, and **immutable types are better suited for multi-threaded environments** because they reduce the synchronization overhead of concurrent variable access. We will discuss this further when we cover concurrent programming.

2. Tuples are immutable types, and typically **immutable types have better creation performance than their mutable counterparts**. We can use the `timeit` function from the `timeit` module to see how long it takes to create tuples and lists containing the same elements. The `number` parameter of the `timeit` function specifies how many times the code is executed. In the code below, we create lists and tuples containing integers `1` through `9`, each operation executed `10000000` times, and measure the running time.

   ```python
   import timeit

   print('%.3f seconds' % timeit.timeit('[1, 2, 3, 4, 5, 6, 7, 8, 9]', number=10000000))
   print('%.3f seconds' % timeit.timeit('(1, 2, 3, 4, 5, 6, 7, 8, 9)', number=10000000))
   ```

   Output:

   ```
   0.635 seconds
   0.078 seconds
   ```

   > **Note**: The results above vary depending on your hardware and software system. On my current computer, executing `10000000` list creation operations takes `0.635` seconds, while `10000000` tuple creation operations takes `0.078` seconds. Clearly, creating tuples is faster, with an order-of-magnitude difference. You can run this code on your own computer and share your results in the comments to see whose computer is more powerful.

Of course, tuples and lists in Python can be converted to each other, as shown below.

```python
infos = ('Luo Hao', 45, True, 'Chengdu, Sichuan')
# Convert tuple to list
print(list(infos))  # ['Luo Hao', 45, True, 'Chengdu, Sichuan']

frts = ['apple', 'banana', 'orange']
# Convert list to tuple
print(tuple(frts))  # ('apple', 'banana', 'orange')
```

### Summary

**Both lists and tuples are container-type data types**, meaning a single variable can hold multiple data values, and they are both ordered containers that organize elements in a specific order. **Lists are mutable data types**, while **tuples are immutable data types**. This means lists support adding, removing, clearing, sorting, and reversing elements, but these operations are not applicable to tuples. Both lists and tuples support **concatenation**, **membership operations**, **indexing**, and **slicing**. The string type we'll cover later also supports these operations, since strings are sequences of characters arranged in order -- in this respect, all three are the same. We **recommend using list comprehension syntax to create lists**, as it is not only convenient but also highly efficient, and is a distinctive feature of the Python language.
