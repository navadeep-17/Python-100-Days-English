The world's first general-purpose electronic computer was named ENIAC (Electronic Numerical Integrator and Computer), born at the University of Pennsylvania in the United States. It occupied 167 square meters, weighed about 27 tons, and could perform approximately 5,000 floating-point operations per second, as shown in the image below. After its creation, ENIAC was used for calculating missile trajectories, and numerical computation has remained one of the most important functions of modern electronic computers.

As time has progressed, although numerical computation still constitutes the most important part of a computer's daily work, today's computers also need to process large amounts of text-based information. If we want to manipulate such text information through Python programs, we must first understand the string data type and its related operations and methods.

### Defining Strings

A **string** is a **finite sequence composed of zero or more characters**, generally denoted as:

$$
s = a_1a_2 \cdots a_n \,\,\,\,\, (0 \le n \le \infty)
$$

In a Python program, we can represent a string by enclosing one or more characters in single or double quotes. Characters in a string can be special symbols, English letters, Chinese characters, Japanese hiragana or katakana, Greek letters, Emoji characters (e.g., 💩, 🐷, 🀄️), and more.

```python
s1 = 'hello, world!'
s2 = "你好，世界！❤️"
s3 = '''hello,
wonderful
world!'''
print(s1)
print(s2)
print(s3)
```

#### Escape Characters

We can use `\` (backslash) in a string to indicate an escape, meaning the character following `\` no longer has its original meaning. For example, `\n` does not represent the characters `\` and `n`, but rather a newline; `\t` does not represent `\` and `t`, but rather a tab character. Therefore, if a string itself contains special characters like `'`, `"`, or `\`, they must be escaped using `\`. For example, to output a string with a single quote or a backslash, you would use the following approach.

```python
s1 = '\'hello, world!\''
s2 = '\\hello, world!\\'
print(s1)
print(s2)
```

#### Raw Strings

In Python, there is a type of string prefixed with `r` or `R`, called a raw string. It means that every character in the string retains its literal meaning, with no escape characters. For example, in the string `'hello\n'`, `\n` represents a newline; but in `r'hello\n'`, `\n` no longer means a newline — it is simply the characters `\` and `n`. You can run the code below to see what it outputs.

```python
s1 = '\it \is \time \to \read \now'
s2 = r'\it \is \time \to \read \now'
print(s1)
print(s2)
```

> **Note**: In the variable `s1` above, `\t`, `\r`, and `\n` are all escape characters. `\t` is a tab character (table), `\n` is a newline character (new line), and `\r` is a carriage return character (carriage return), which moves the output back to the beginning of the line. Compare the output of the two `print` functions to see the difference!

#### Special Character Representations

Python also allows you to use an octal or hexadecimal number after `\` to represent a character. For example, `\141` and `\x61` both represent the lowercase letter `a` — the former uses octal notation and the latter uses hexadecimal notation. Another way to represent characters is by following `\u` with a Unicode character code. For example, `\u9a86\u660a` represents the Chinese characters "骆昊". Run the code below to see the output.

```python
s1 = '\141\142\143\x61\x62\x63'
s2 = '\u9a86\u660a'
print(s1)
print(s2)
```

### String Operations

Python provides a very rich set of operators for the string type, many of which work similarly to those for the list type. For example, we can use the `+` operator to concatenate strings, the `*` operator to repeat a string's content, `in` and `not in` to check whether one string contains another, and `[]` and `[:]` to extract characters or substrings from a string.

#### Concatenation and Repetition

The example below demonstrates using the `+` and `*` operators to concatenate and repeat strings.

```python
s1 = 'hello' + ', ' + 'world'
print(s1)    # hello, world
s2 = '!' * 3
print(s2)    # !!!
s1 += s2
print(s1)    # hello, world!!!
s1 *= 2
print(s1)    # hello, world!!!hello, world!!!
```

Using `*` to repeat a string is a very interesting operator. In many programming languages, to represent a string of 10 `a`'s, you can only write `'aaaaaaaaaa'`, but in Python, you can write `'a' * 10`. You might think that `'aaaaaaaaaa'` is not that inconvenient, but consider what would happen if the character `a` needed to be repeated 100 or 1000 times!

#### Comparison Operations

For two string variables, you can directly use comparison operators to check equality or compare their order. It is worth noting that since strings are stored in binary form in computer memory, comparing strings compares the encoding value of each character. For example, the encoding for `A` is `65`, while the encoding for `a` is `97`, so the result of `'A' < 'a'` is equivalent to `65 < 97`, which is obviously `True`. For `'boy' < 'bad'`, since the first characters are both `'b'` and cannot determine the order, the comparison moves to the second character, and since `'o' < 'a'` is `False`, the result of `'boy' < 'bad'` is `False`. If you are unsure about the encoding values of two characters, you can use the `ord` function, which we mentioned before. For example, `ord('A')` returns `65`, and `ord('昊')` returns `26122`. The code below demonstrates string comparison operations — please look at it carefully.

```python
s1 = 'a whole new world'
s2 = 'hello world'
print(s1 == s2)             # False
print(s1 < s2)              # True
print(s1 == 'hello world')  # False
print(s2 == 'hello world')  # True
print(s2 != 'Hello world')  # True
s3 = '骆昊'
print(ord('骆'))            # 39558
print(ord('昊'))            # 26122
s4 = '王大锤'
print(ord('王'))            # 29579
print(ord('大'))            # 22823
print(ord('锤'))            # 38180
print(s3 >= s4)             # True
print(s3 != s4)             # True
```

#### Membership Operations

In Python, you can use `in` and `not in` to check whether a string contains another character or string. Just like with lists, `in` and `not in` are called membership operators and produce a boolean value of `True` or `False`, as shown below.

```python
s1 = 'hello, world'
s2 = 'goodbye, world'
print('wo' in s1)      # True
print('wo' not in s2)  # False
print(s2 in s1)        # False
```

#### Getting String Length

Getting the length of a string works the same way as getting the number of elements in a list — using the built-in function `len`, as shown below.

```python
s = 'hello, world'
print(len(s))                 # 12
print(len('goodbye, world'))  # 14
```

#### Indexing and Slicing

String indexing and slicing operations are almost identical to those for lists and tuples, since strings are also ordered sequences and can be accessed by positive or negative integer indices. However, one thing to note is that since **strings are immutable types**, you **cannot modify characters in a string through indexing**.

```python
s = 'abc123456'
n = len(s)
print(s[0], s[-n])    # a a
print(s[n-1], s[-1])  # 6 6
print(s[2], s[-7])    # c c
print(s[5], s[-4])    # 3 3
print(s[2:5])         # c12
print(s[-7:-4])       # c12
print(s[2:])          # c123456
print(s[:2])          # ab
print(s[::2])         # ac246
print(s[::-1])        # 654321cba
```

A reminder once again: when performing indexing operations, if the index is out of bounds, an `IndexError` exception will be raised with the error message: `string index out of range`.

### Iterating Over Characters

If you want to iterate over each character in a string, you can use a `for-in` loop. There are two approaches as shown below.

Approach 1:

```python
s = 'hello'
for i in range(len(s)):
    print(s[i])
```

Approach 2:

```python
s = 'hello'
for elem in s:
    print(elem)
```

### String Methods

In Python, we can use the built-in methods of the string type to operate on and process strings. Suppose we have a string named `foo` with a method named `bar`. The syntax for using the string method is: `foo.bar()`. This is the syntax for calling an object's method through an object reference, the same as using list methods we learned before.

#### Case-Related Operations

The code below demonstrates methods related to changing string case.

```python
s1 = 'hello, world!'
# Capitalize the first letter of the string
print(s1.capitalize())  # Hello, world!
# Capitalize the first letter of each word
print(s1.title())       # Hello, World!
# Convert the string to uppercase
print(s1.upper())       # HELLO, WORLD!
s2 = 'GOODBYE'
# Convert the string to lowercase
print(s2.lower())       # goodbye
# Check the values of s1 and s2
print(s1)               # hello, world
print(s2)               # GOODBYE
```

> **Note**: Since strings are immutable types, using string methods to operate on a string produces a new string, but the original variable's value does not change. So in the code above, when we check the values of `s1` and `s2` at the end, they remain unchanged.

#### Find Operations

To search for another string within a string from left to right, you can use the `find` or `index` method. When using `find` and `index`, you can also specify the search range through method parameters, meaning the search does not have to start from index `0`.

```python
s = 'hello, world!'
print(s.find('or'))      # 8
print(s.find('or', 9))   # -1
print(s.find('of'))      # -1
print(s.index('or'))     # 8
print(s.index('or', 9))  # ValueError: substring not found
```

> **Note**: The `find` method returns `-1` when the specified string is not found, while the `index` method raises a `ValueError` when the specified string is not found.

The `find` and `index` methods also have reverse search (right-to-left) versions, namely `rfind` and `rindex`, as shown below.

```python
s = 'hello world!'
print(s.find('o'))       # 4
print(s.rfind('o'))      # 7
print(s.rindex('o'))     # 7
# print(s.rindex('o', 8))  # ValueError: substring not found
```

#### Property Checks

You can use the `startswith` and `endswith` methods to check whether a string starts or ends with a certain substring. You can also use methods starting with `is` to check string properties — these methods all return boolean values, as shown below.

```python
s1 = 'hello, world!'
print(s1.startswith('He'))   # False
print(s1.startswith('hel'))  # True
print(s1.endswith('!'))      # True
s2 = 'abc123456'
print(s2.isdigit())  # False
print(s2.isalpha())  # False
print(s2.isalnum())  # True
```

> **Note**: The `isdigit` method above checks whether the string consists entirely of digits. `isalpha` checks whether the string consists entirely of letters — here "letters" refers to Unicode characters but not Emoji characters. `isalnum` checks whether the string consists of letters and digits.

#### Formatting

In Python, the string type can be centered, left-aligned, or right-aligned using the `center`, `ljust`, and `rjust` methods. If you need to pad the left side of a string with zeros, you can also use the `zfill` method.

```python
s = 'hello, world'
print(s.center(20, '*'))  # ****hello, world****
print(s.rjust(20))        #         hello, world
print(s.ljust(20, '~'))   # hello, world~~~~~~~~
print('33'.zfill(5))      # 00033
print('-33'.zfill(5))     # -0033
```

As we mentioned before, when using the `print` function to output strings, you can format the string in the following way.

```python
a = 321
b = 123
print('%d * %d = %d' % (a, b, a * b))
```

Of course, we can also use the string's `format` method to accomplish string formatting, as shown below.

```python
a = 321
b = 123
print('{0} * {1} = {2}'.format(a, b, a * b))
```

Starting from Python 3.6, there is an even more concise way to format strings — by prefixing the string with `f`. In such f-strings, `{variable_name}` serves as a placeholder that will be replaced by the corresponding variable's value, as shown below.

```python
a = 321
b = 123
print(f'{a} * {b} = {a * b}')
```

If you need further control over the format of variable values in the formatting syntax, you can refer to the table below for string formatting operations.

| Value       | Placeholder | Formatted Result | Description |
| ----------- | ---------- | ------------- | ---- |
| `3.1415926` | `{:.2f}`   | `'3.14'`      | Keep two decimal places |
| `3.1415926` | `{:+.2f}`  | `'+3.14'`       | Keep two decimal places with sign |
| `-1`        | `{:+.2f}`  | `'-1.00'` | Keep two decimal places with sign |
| `3.1415926` | `{:.0f}`   | `'3'` | No decimal places |
| `123`       | `{:0>10d}` | `'0000000123'` | Pad with `0` on the left to fill 10 digits |
| `123`       | `{:x<10d}` | `'123xxxxxxx'` | Pad with `x` on the right to fill 10 digits |
| `123`       | `{:>10d}`  | `'       123'` | Pad with spaces on the left to fill 10 digits |
| `123`       | `{:<10d}` | `'123       '` | Pad with spaces on the right to fill 10 digits |
| `123456789` | `{:,}`     | `'123,456,789'` | Comma-separated format |
| `0.123`     | `{:.2%}`   | `'12.30%'`    | Percentage format |
| `123456789` | `{:.2e}`   | `'1.23e+08'`  | Scientific notation format |

#### Trimming Operations

The string's `strip` method can trim specified characters from both ends of the original string, defaulting to trimming whitespace characters. This method is very practical and can be used to remove leading and trailing spaces that a user might accidentally type. The `strip` method also has `lstrip` and `rstrip` variants — you can probably guess from the names what these two methods do.

```python
s1 = '   jackfrued@126.com  '
print(s1.strip())      # jackfrued@126.com
s2 = '~你好，世界~'
print(s2.lstrip('~'))  # 你好，世界~
print(s2.rstrip('~'))  # ~你好，世界
```

#### Replacement Operations

If you want to replace specified content in a string with new content, you can use the `replace` method, as shown below. The first parameter of `replace` is the content to be replaced, the second parameter is the replacement content, and you can also specify the number of replacements through a third parameter.

```python
s = 'hello, good world'
print(s.replace('o', '@'))     # hell@, g@@d w@rld
print(s.replace('o', '@', 1))  # hell@, good world
```

#### Splitting and Joining

You can use the string's `split` method to split a string into multiple strings (stored in a list), and use the string's `join` method to concatenate multiple strings in a list into a single string, as shown below.

```python
s = 'I love you'
words = s.split()
print(words)            # ['I', 'love', 'you']
print('~'.join(words))  # I~love~you
```

Note that the `split` method uses whitespace as the default delimiter. You can also specify a different character for splitting, and control the splitting behavior by specifying a maximum number of splits, as shown below.

```python
s = 'I#love#you#so#much'
words = s.split('#')
print(words)  # ['I', 'love', 'you', 'so', 'much']
words = s.split('#', 2)
print(words)  # ['I', 'love', 'you#so#much']
```

#### Encoding and Decoding

In Python, besides the string type `str`, there is also a bytes type (`bytes`) that represents binary data. A bytes object is a **finite sequence composed of zero or more bytes**. Using the string's `encode` method, we can encode a string into a bytes object according to a specified encoding scheme. We can also use the bytes object's `decode` method to decode it back into a string, as shown below.

```python
a = '骆昊'
b = a.encode('utf-8')
c = a.encode('gbk')
print(b)                  # b'\xe9\xaa\x86\xe6\x98\x8a'
print(c)                  # b'\xc2\xe6\xea\xbb'
print(b.decode('utf-8'))  # 骆昊
print(c.decode('gbk'))    # 骆昊
```

Note that if the encoding and decoding methods are inconsistent, it will cause garbled text (the original content cannot be reproduced) or raise a `UnicodeDecodeError`, causing the program to crash.

#### Other Methods

For the string type, another commonly used operation is pattern matching — checking whether a string matches a certain specific pattern. For example, a website's validation of usernames and emails during user registration is a form of pattern matching. The tool for implementing pattern matching is called regular expressions. Python provides support for regular expressions through the `re` module in the standard library, which we will cover in a later lesson.
