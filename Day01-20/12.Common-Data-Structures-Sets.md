## Common Data Structures - Sets

After learning about lists and tuples, let's learn another container data type called a set. The word "set" should be very familiar — it is a concept from math textbooks. If we **treat a range of definite, distinguishable things as a whole**, then this whole is a set, and each thing in the set is called an **element** of the set. Typically, a set must satisfy the following requirements:

1. **Unorderedness**: In a set, every element has equal status, and there is no order among elements.
2. **Uniqueness**: In a set, no two elements are the same — each element can only appear once in the set.
3. **Determinacy**: Given a set and any element, that element either belongs to the set or does not — there is no ambiguity allowed.

Sets in Python programs are essentially no different from mathematical sets. What needs to be emphasized are the unorderedness and uniqueness mentioned above. Unorderedness means that elements in a set do not have a specific order like elements in a list, and cannot be accessed via indexing — **sets do not support indexing operations**. Additionally, the uniqueness of sets means that **a set cannot contain duplicate elements**, which is what distinguishes sets from lists — we cannot add duplicate elements to a set. The set type naturally supports `in` and `not in` membership operations, which allow us to determine whether an element belongs to a set — this is the determinacy mentioned above. **Membership operations on sets perform better than those on lists**, which is determined by the underlying storage characteristics of sets. We will not discuss this in detail for now — just remember this conclusion.

> **Note**: Sets use hash storage (also known as hash tables) internally. Readers unfamiliar with hash storage can check out the [Hash Table](https://www.hello-algo.com/chapter_hashing/) section on the "Hello Algorithm" website. Thanks to the author for their open-source spirit.

### Creating Sets

In Python, sets can be created using `{}` literal syntax. The `{}` must contain at least one element, because an empty `{}` is not an empty set but an empty dictionary — we will introduce the dictionary type in the next lesson. You can also use Python's built-in function `set` to create a set. Strictly speaking, `set` is not a function but a constructor for creating set objects — this concept will be introduced later when we discuss object-oriented programming. You can use the `set` function to create an empty set, or use it to convert other sequences into sets. For example, `set('hello')` produces a set containing `4` characters (the duplicate character `l` will only appear once in the set). Besides these two methods, you can also use comprehension syntax to create sets, just as we used comprehension syntax to create lists before.

```python
set1 = {1, 2, 3, 3, 3, 2}
print(set1)

set2 = {'banana', 'pitaya', 'apple', 'apple', 'banana', 'grape'}
print(set2)

set3 = set('hello')
print(set3)

set4 = set([1, 2, 2, 3, 3, 3, 2, 1])
print(set4)

set5 = {num for num in range(1, 20) if num % 3 == 0 or num % 7 == 0}
print(set5)
```

A reminder: elements in a set must be of a `hashable` type. A `hashable` type is a data type for which a hash code can be computed. Typically, immutable types are `hashable`, such as integers (`int`), floating-point numbers (`float`), booleans (`bool`), strings (`str`), tuples (`tuple`), etc. Mutable types are not `hashable` because a definite hash code cannot be computed for them, so they cannot be placed in a set. For example, we cannot use a list as an element of a set; similarly, since sets themselves are mutable types, a set cannot be an element of another set. We can create nested lists (lists whose elements are also lists), but we cannot create nested sets — this must be kept in mind when using sets.

> **Tip**: If you don't understand the concepts of hash codes and hash storage mentioned above, you can set them aside for now, as they won't affect your ability to continue learning and using Python. However, if you are a computer science major, not understanding hash storage is hard to forgive — you should catch up on this soon.

### Iterating Over Elements

We can use the `len` function to get the number of elements in a set, but we cannot traverse set elements through indexing because set elements have no specific order. To iterate over set elements, we can still use a `for-in` loop, as shown below.

```python
set1 = {'Python', 'C++', 'Java', 'Kotlin', 'Swift'}
for elem in set1:
    print(elem)
```

> **Tip**: Look at the output of the code above and observe the order in which the words are printed to appreciate the unorderedness of sets.

### Set Operations

Python provides a very rich set of operations for the set type, mainly including: membership operations, intersection, union, difference, comparison operations (equality, subset, superset), and more.

#### Membership Operations

You can use the membership operators `in` and `not in` to check whether an element is in a set, as shown below.

```python
set1 = {11, 12, 13, 14, 15}
print(10 in set1)      # False
print(15 in set1)      # True
set2 = {'Python', 'Java', 'C++', 'Swift'}
print('Ruby' in set2)  # False
print('Java' in set2)  # True
```

#### Binary Operations

Binary operations on sets mainly refer to intersection, union, difference, and symmetric difference. These operations can be performed using operators or set methods, as shown below.

<img src="res/day12/set_operations.png" style="zoom:50%;">

```python
set1 = {1, 2, 3, 4, 5, 6, 7}
set2 = {2, 4, 6, 8, 10}

# Intersection
print(set1 & set2)                      # {2, 4, 6}
print(set1.intersection(set2))          # {2, 4, 6}

# Union
print(set1 | set2)                      # {1, 2, 3, 4, 5, 6, 7, 8, 10}
print(set1.union(set2))                 # {1, 2, 3, 4, 5, 6, 7, 8, 10}

# Difference
print(set1 - set2)                      # {1, 3, 5, 7}
print(set1.difference(set2))            # {1, 3, 5, 7}

# Symmetric difference
print(set1 ^ set2)                      # {1, 3, 5, 7, 8, 10}
print(set1.symmetric_difference(set2))  # {1, 3, 5, 7, 8, 10}
```

From the code above, you can see that the `&` operator and the `intersection` method produce exactly the same result when computing the intersection of two sets. Using operators is obviously more intuitive and results in shorter code. It should be noted that binary set operations can also be combined with assignment operators to form compound assignment operations. For example, `set1 |= set2` is equivalent to `set1 = set1 | set2`, and the method equivalent to `|=` is `update`; `set1 &= set2` is equivalent to `set1 = set1 & set2`, and the method equivalent to `&=` is `intersection_update`, as shown below.

```python
set1 = {1, 3, 5, 7}
set2 = {2, 4, 6}
set1 |= set2
# set1.update(set2)
print(set1)  # {1, 2, 3, 4, 5, 6, 7}
set3 = {3, 6, 9}
set1 &= set3
# set1.intersection_update(set3)
print(set1)  # {3, 6}
set2 -= set1
# set2.difference_update(set1)
print(set2)  # {2, 4}
```

#### Comparison Operations

Two sets can be compared for equality using `==` and `!=`. If the elements in two sets are exactly the same, the `==` comparison returns `True`; otherwise it returns `False`. If every element of set `A` is also an element of set `B`, then set `A` is called a subset of set `B`. That is, for $\small{\forall{a} \in {A}}$, we have $\small{{a} \in {B}}$, then $\small{{A} \subseteq {B}}$ — `A` is a subset of `B`, and conversely, `B` is a superset of `A`. If `A` is a subset of `B` and `A` is not equal to `B`, then `A` is a proper subset of `B`. Python provides operators for checking subset and superset relationships, which are the familiar `<`, `<=`, `>`, `>=` operators. Of course, you can also use the set methods `issubset` and `issuperset` to check relationships between sets, as shown below.

```python
set1 = {1, 3, 5}
set2 = {1, 2, 3, 4, 5}
set3 = {5, 4, 3, 2, 1}

print(set1 < set2)   # True
print(set1 <= set2)  # True
print(set2 < set3)   # False
print(set2 <= set3)  # True
print(set2 > set1)   # True
print(set2 == set3)  # True

print(set1.issubset(set2))    # True
print(set2.issuperset(set1))  # True
```

> **Note**: In the code above, `set1 < set2` checks whether `set1` is a proper subset of `set2`, `set1 <= set2` checks whether `set1` is a subset of `set2`, and `set2 > set1` checks whether `set2` is a superset of `set1`. Of course, we can also use `set1.issubset(set2)` to check if `set1` is a subset of `set2`, and `set2.issuperset(set1)` to check if `set2` is a superset of `set1`.

### Set Methods

As we mentioned, sets in Python are mutable types. We can add elements to a set or remove elements from it using set methods.

```python
set1 = {1, 10, 100}

# Add elements
set1.add(1000)
set1.add(10000)
print(set1)  # {1, 100, 1000, 10, 10000}

# Remove elements
set1.discard(10)
if 100 in set1:
    set1.remove(100)
print(set1)  # {1, 1000, 10000}

# Clear all elements
set1.clear()
print(set1)  # set()
```

> **Note**: The `remove` method raises a `KeyError` if the element does not exist, which is why in the code above, we first check membership before removing. The set type also has a `pop` method that randomly removes an element from the set. This method returns the removed element, whereas `remove` and `discard` only remove the element without returning it.

The set type also has a method called `isdisjoint` that checks whether two sets have any common elements. If there are no common elements, the method returns `True`; otherwise it returns `False`, as shown below.

```python
set1 = {'Java', 'Python', 'C++', 'Kotlin'}
set2 = {'Kotlin', 'Swift', 'Java', 'Dart'}
set3 = {'HTML', 'CSS', 'JavaScript'}
print(set1.isdisjoint(set2))  # False
print(set1.isdisjoint(set3))  # True
```

### Frozen Sets

Python also has an immutable set type called `frozenset`. The difference between `set` and `frozenset` is similar to the difference between `list` and `tuple`. Since `frozenset` is immutable, a hash code can be computed for it, which means it can be used as an element of a `set`. Except for being unable to add or remove elements, `frozenset` is the same as `set` in all other aspects. The code below briefly demonstrates the usage of `frozenset`.

```python
fset1 = frozenset({1, 3, 5, 7})
fset2 = frozenset(range(1, 6))
print(fset1)          # frozenset({1, 3, 5, 7})
print(fset2)          # frozenset({1, 2, 3, 4, 5})
print(fset1 & fset2)  # frozenset({1, 3, 5})
print(fset1 | fset2)  # frozenset({1, 2, 3, 4, 5, 7})
print(fset1 - fset2)  # frozenset({7})
print(fset1 < fset2)  # False
```

### Summary

The **set type in Python is an unordered container** that **does not allow duplicate elements**. Since it uses hash storage internally, set elements must be of a `hashable` type. The biggest difference between sets and lists is that **set elements have no order**, so they **cannot be accessed via indexing**. However, sets can perform binary operations such as intersection, union, and difference, and can use relational operators to check for superset and subset relationships.
