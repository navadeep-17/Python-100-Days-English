## Common Data Structures - Dictionaries

So far, we have introduced three container data types in Python (lists, tuples, and sets), but these data types are still not sufficient to help us solve all problems. For example, suppose we need a variable to store multiple pieces of information about a person, including: name, age, height, weight, home address, personal phone number, and emergency contact phone number. You'll find that the lists, tuples, and sets we've learned are not ideal for this purpose.

```python
person1 = ['王大锤', 55, 168, 60, '成都市武侯区科华北路62号1栋101', '13122334455', '13800998877']
person2 = ('王大锤', 55, 168, 60, '成都市武侯区科华北路62号1栋101', '13122334455', '13800998877')
person3 = {'王大锤', 55, 168, 60, '成都市武侯区科华北路62号1栋101', '13122334455', '13800998877'}
```

A set is definitely the least suitable option, because sets cannot have duplicate elements — if a person's age and weight happen to be the same, the set would be missing one piece of information. Similarly, if the person's phone number and emergency contact number are the same, the set would again lose an item. On the other hand, while lists and tuples can store all of a person's information, when you want to retrieve the person's phone number or home address, you need to know which position in the list or tuple the phone number occupies. In short, when facing the scenarios described above, lists, tuples, and sets are not the best choices. What we need is the dictionary type, which is the most suitable data type for assembling related information together and can help us model real-world things in Python programs.

The word "dictionary" should be very familiar — when we were in elementary school, nearly everyone had a copy of the Xinhua Dictionary, as shown in the image below.

<img src="res/day13/xinhua_dictionary.jpg" style="zoom:80%;">

A dictionary in Python is very similar to a real-world dictionary. It organizes data using key-value pairs (combinations of keys and values), and we can look up and operate on values through their corresponding keys. Just as in the Xinhua Dictionary, every character (key) has a corresponding definition (value), each character and its definition together form an entry in the dictionary, and a dictionary typically contains many such entries.

### Creating and Using Dictionaries

In Python, dictionaries can be created using `{}` literal syntax, which is the same as what we covered for sets in the previous lesson. However, elements in a dictionary's `{}` exist as key-value pairs, with each element consisting of two values separated by `:` — the part before `:` is the key, and the part after `:` is the value, as shown below.

```python
xinhua = {
    '麓': '山脚下',
    '路': '道，往来通行的地方；方面，地区：南～货，外～货；种类：他俩是一～人',
    '蕗': '甘草的别名',
    '潞': '潞水，水名，即今山西省的浊漳河；潞江，水名，即云南省的怒江'
}
print(xinhua)
person = {
    'name': '王大锤',
    'age': 55,
    'height': 168,
    'weight': 60,
    'addr': '成都市武侯区科华北路62号1栋101',
    'tel': '13122334455',
    'emergence contact': '13800998877'
}
print(person)
```

From the code above, you can see that using a dictionary to store a person's information is far superior to using a list or tuple, because we can use the key before `:` to describe the meaning of each entry, and the part after `:` is the corresponding value.

Of course, if you prefer, you can also use the built-in function `dict` or dictionary comprehension syntax to create a dictionary, as shown below.

```python
# Each set of parameters in the dict function (constructor) is a key-value pair in the dictionary
person = dict(name='王大锤', age=55, height=168, weight=60, addr='成都市武侯区科华北路62号1栋101')
print(person)  # {'name': '王大锤', 'age': 55, 'height': 168, 'weight': 60, 'addr': '成都市武侯区科华北路62号1栋101'}

# You can use the built-in zip function to zip two sequences and create a dictionary
items1 = dict(zip('ABCDE', '12345'))
print(items1)  # {'A': '1', 'B': '2', 'C': '3', 'D': '4', 'E': '5'}
items2 = dict(zip('ABCDE', range(1, 10)))
print(items2)  # {'A': 1, 'B': 2, 'C': 3, 'D': 4, 'E': 5}

# Create a dictionary using dictionary comprehension syntax
items3 = {x: x ** 3 for x in range(1, 6)}
print(items3)  # {1: 1, 2: 8, 3: 27, 4: 64, 5: 125}
```

To find out how many key-value pairs are in a dictionary, you still use the `len` function. To iterate over a dictionary, you can use a `for` loop, but note that the `for` loop only iterates over the dictionary's keys. Don't worry though — after learning about dictionary indexing, we can access the corresponding value through each key.

```python
person = {
    'name': '王大锤',
    'age': 55,
    'height': 168,
    'weight': 60,
    'addr': '成都市武侯区科华北路62号1栋101'
}
print(len(person))  # 5
for key in person:
    print(key)
```

### Dictionary Operations

For the dictionary type, membership and indexing operations are certainly very important. The former can determine whether a specified key exists in the dictionary, and the latter can access the corresponding value through a key or add new key-value pairs to the dictionary. It's worth noting that dictionary indexing differs from list indexing — since list elements have sequential numbers, list indexing uses integers; since dictionaries store key-value pairs, dictionary indexing uses keys to look up corresponding values. A **special reminder**: **dictionary keys must be immutable types**, such as integers (`int`), floats (`float`), strings (`str`), tuples (`tuple`), etc. — this requirement is the same as for set elements. Obviously, lists (`list`) and sets (`set`) cannot be used as dictionary keys, and dictionaries themselves cannot be used as keys either, since dictionaries are also mutable types. However, lists, sets, and dictionaries can all be used as dictionary values. For example:

```python
person = {
    'name': '王大锤',
    'age': 55,
    'height': 168,
    'weight': 60,
    'addr': ['成都市武侯区科华北路62号1栋101', '北京市西城区百万庄大街1号'],
    'car': {
        'brand': 'BMW X7',
        'maxSpeed': '250',
        'length': 5170,
        'width': 2000,
        'height': 1835,
        'displacement': 3.0
    }
}
print(person)
```

Take a look at the code below to understand dictionary membership and indexing operations.

```python
person = {'name': '王大锤', 'age': 55, 'height': 168, 'weight': 60, 'addr': '成都市武侯区科华北路62号1栋101'}

# Membership operations
print('name' in person)  # True
print('tel' in person)   # False

# Indexing operations
print(person['name'])
print(person['addr'])
person['age'] = 25
person['height'] = 178
person['tel'] = '13122334455'
person['signature'] = '你的男朋友是一个盖世垃圾，他会踏着五彩祥云去迎娶你的闺蜜'
print(person)

# Loop iteration
for key in person:
    print(f'{key}:\t{person[key]}')
```

Note that when using indexing to get a value from a dictionary, if the specified key does not exist in the dictionary, a `KeyError` exception will be raised.

### Dictionary Methods

Dictionary methods are basically all related to key-value pair operations. The `get` method can retrieve the value corresponding to a key. Unlike indexing, the `get` method does not raise an exception when the specified key is not in the dictionary — it returns `None` or a specified default value, as shown below.

```python
person = {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
print(person.get('name'))       # 王大锤
print(person.get('sex'))        # None
print(person.get('sex', True))  # True
```

To get all keys in a dictionary, use the `keys` method; to get all values, use the `values` method. The dictionary also has an `items` method that assembles keys and values into 2-tuples, making it very convenient to iterate over dictionary elements.

```python
person = {'name': '王大锤', 'age': 25, 'height': 178}
print(person.keys())    # dict_keys(['name', 'age', 'height'])
print(person.values())  # dict_values(['王大锤', 25, 178])
print(person.items())   # dict_items([('name', '王大锤'), ('age', 25), ('height', 178)])
for key, value in person.items():
    print(f'{key}:\t{value}')
```

The dictionary's `update` method merges two dictionaries. For example, given two dictionaries `x` and `y`, when `x.update(y)` is executed, keys that exist in both `x` and `y` will have their values updated to those from `y`, and key-value pairs that exist in `y` but not in `x` will be added directly to `x`, as shown below.

```python
person1 = {'name': '王大锤', 'age': 55, 'height': 178}
person2 = {'age': 25, 'addr': '成都市武侯区科华北路62号1栋101'}
person1.update(person2)
print(person1)  # {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
```

If you are using Python 3.9 or above, you can also use the `|` operator to achieve the same operation, as shown below.

```python
person1 = {'name': '王大锤', 'age': 55, 'height': 178}
person2 = {'age': 25, 'addr': '成都市武侯区科华北路62号1栋101'}
person1 |= person2
print(person1)  # {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
```

You can use `pop` or `popitem` to remove elements from a dictionary. The `pop` method returns the value corresponding to the key, but raises a `KeyError` if the key does not exist. The `popitem` method removes an element and returns a 2-tuple of the key and value. The dictionary's `clear` method clears all key-value pairs, as shown below.

```python
person = {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
print(person.pop('age'))  # 25
print(person)             # {'name': '王大锤', 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
print(person.popitem())   # ('addr', '成都市武侯区科华北路62号1栋101')
print(person)             # {'name': '王大锤', 'height': 178}
person.clear()
print(person)             # {}
```

Just like with lists, you can also use the `del` keyword to remove elements from a dictionary. If the specified key does not map to a value, a `KeyError` will be raised, as shown below.

```python
person = {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都市武侯区科华北路62号1栋101'}
del person['age']
del person['addr']
print(person)  # {'name': '王大锤', 'height': 178}
```

### Dictionary Applications

Let's look at a few simple examples to see how to use dictionaries to solve some practical problems.

**Example 1**: Given a paragraph of text, count the occurrences of each English letter and output the results in descending order of frequency.

```python
sentence = input('Please enter a sentence: ')
counter = {}
for ch in sentence:
    if 'A' <= ch <= 'Z' or 'a' <= ch <= 'z':
        counter[ch] = counter.get(ch, 0) + 1
sorted_keys = sorted(counter, key=counter.get, reverse=True)
for key in sorted_keys:
    print(f'{key} appeared {counter[key]} times.')
```

Input:

```
Man is distinguished, not only by his reason, but by this singular passion from other animals, which is a lust of the mind, that by a perseverance of delight in the continued and indefatigable generation of knowledge, exceeds the short vehemence of any carnal pleasure.
```

**Example 2**: Given a dictionary that stores stock codes and prices, find the stocks with prices greater than 100 and create a new dictionary.

> **Note**: You can use dictionary comprehension syntax to create this new dictionary.

```python
stocks = {
    'AAPL': 191.88,
    'GOOG': 1186.96,
    'IBM': 149.24,
    'ORCL': 48.44,
    'ACN': 166.89,
    'FB': 208.09,
    'SYMC': 21.29
}
stocks2 = {key: value for key, value in stocks.items() if value > 100}
print(stocks2)
```

Output:

```
{'AAPL': 191.88, 'GOOG': 1186.96, 'IBM': 149.24, 'ACN': 166.89, 'FB': 208.09}
```

### Summary

Dictionaries in Python are very similar to real-world dictionaries, allowing us to **store data as key-value pairs** and **access corresponding values through keys**. Dictionaries are a data type that is very **advantageous for data retrieval**, but once again, **dictionary keys must be immutable types** — data types like lists, sets, and dictionaries cannot be used as dictionary keys.
