## Advanced Function Usage

Let's continue exploring how to define and use functions. From previous lessons, we know that functions have independent variables (parameters) and dependent variables (return values), and both can be of any data type. This raises a small question: can we use a function as a function's parameter, or use a function as a function's return value? Here's the conclusion first: **functions in Python are "first-class functions"**. The term "first-class functions" means that functions can be assigned to variables, functions can be used as arguments to other functions, and functions can also be used as return values of other functions. The practice of using a function as the parameter or return value of another function is commonly called a "higher-order function".

### Higher-Order Functions

Let's revisit an earlier example: designing a function that takes any number of arguments and sums only the `int` and `float` type elements. We'll make slight adjustments to the previous code to make it more compact, as shown below.

```python
def calc(*args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = 0
    for item in items:
        if type(item) in (int, float):
            result += item
    return result
```

What if we want the `calc` function above to not only sum multiple arguments, but also perform more operations, even custom binary operations? The code above can only perform summation because it uses the `+=` operator, which couples the function to the addition operation. If we can decouple this relationship, the function will become more versatile and flexible. The way to decouple is to turn the `+` operator into a function call and make it a parameter of the function, as shown below.

```python
def calc(init_value, op_func, *args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = init_value
    for item in items:
        if type(item) in (int, float):
            result = op_func(result, item)
    return result
```

Note that the function above has two new parameters: `init_value` represents the initial value for the operation, and `op_func` represents the binary operation function. To call the modified function, we first define functions for addition and multiplication, as shown below.

```python
def add(x, y):
    return x + y


def mul(x, y):
    return x * y
```

To perform a summation, we can call the `calc` function as follows.

```python
print(calc(0, add, 1, 2, 3, 4, 5))  # 15
```

To perform a product operation, we can call the `calc` function as follows.

```python
print(calc(1, mul, 1, 2, 3, 4, 5))  # 120
```

The `calc` function above achieves decoupling from the addition operation by turning the operator into a function parameter. This is a very clever and practical programming technique, though beginners may find it hard to understand at first — take some time to think it through. Note that there is a significant difference between passing a function as an argument and calling a function directly: calling a function requires parentheses after the function name, while passing a function as an argument only requires the function name**.

If we don't have `add` and `mul` functions defined in advance, we can also use the `add` and `mul` functions from Python's standard library `operator` module, which represent binary addition and multiplication operations respectively. We can use them directly, as shown below.

```python
import operator

print(calc(0, operator.add, 1, 2, 3, 4, 5))  # 15
print(calc(1, operator.mul, 1, 2, 3, 4, 5))  # 120
```

Python has many built-in higher-order functions. The `filter` and `map` functions we mentioned before are higher-order functions — the former can filter elements in a sequence, and the latter can map elements in a sequence. For example, to remove odd numbers from an integer list and square all even numbers to get a new list, we can use these two functions directly, as shown below.

```python
def is_even(num):
    """Check if num is even"""
    return num % 2 == 0


def square(num):
    """Calculate the square"""
    return num ** 2


old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(square, filter(is_even, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

Of course, to achieve the same functionality as the code above, you can also use a list comprehension, which is simpler and more elegant.

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = [num ** 2 for num in old_nums if num % 2 == 0]
print(new_nums)  # [144, 64, 3600, 2704]
```

Let's discuss another built-in function, `sorted`, which can sort elements of container data types (such as lists, dictionaries, etc.). We previously covered the `sort` method of the `list` type, which sorts list elements in-place. Functionally, `sorted` is no different from the list's `sort` method, but it returns a new sorted list instead of modifying the original one — this is what we call **side-effect-free function design**, meaning that calling the function produces no effects other than returning a value. When using `sorted`, you can customize sorting rules through a higher-order function approach. Let's illustrate this with the following example.

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings)
print(new_strings)  # ['apple', 'in', 'pear', waxberry', 'zoo']
```

The code above should look familiar, but if we want to sort the list elements by string length rather than alphabetical order, we can pass a `key` parameter to the `sorted` function, setting `key` to the `len` function (which gets the string length), as shown below.

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings, key=len)
print(new_strings)  # ['in', 'zoo', 'pear', 'apple', 'waxberry']
```

> **Note**: The `sort` method of the list type also has the same `key` parameter. Interested readers can try it on their own.

### Lambda Functions

When using higher-order functions, if the function used as a parameter or return value is very simple (just one line of code) and doesn't need a name for reuse, we can use a lambda function. A lambda function in Python is a function without a name, so many people call it an **anonymous function**. A lambda function can only have one line of code, and the result of the expression in that line is the return value of the anonymous function. In the earlier code, the `is_even` and `square` functions each had only one line of code, so we can consider replacing them with lambda functions, as shown below.

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

Lambda functions are essentially anonymous functions. Next, let's see how to use lambda functions.

As you can see from the code above, the keyword for defining a lambda function is `lambda`, followed by the function's parameters (if there are multiple parameters, separate them with commas). After the colon is the function body, which is usually an expression whose result is the lambda function's return value — no `return` keyword is needed.

As we mentioned, functions in Python are "first-class functions" that can be directly assigned to variables. After learning about lambda functions, some of the functions we wrote before can be implemented in a single line of code. See if you can understand the factorial and prime-checking functions below.

```python
import functools
import operator

# Implement a factorial function in one line of code
fac = lambda n: functools.reduce(operator.mul, range(2, n + 1), 1)

# Implement a prime-checking function in one line of code
is_prime = lambda x: all(map(lambda f: x % f, range(2, int(x ** 0.5) + 1)))

# Call lambda functions
print(fac(6))        # 720
print(is_prime(37))  # True
```

> **Tip 1**: The `reduce` function used above is from the `functools` module in Python's standard library. It performs a reduction operation on a collection of data, similar to the `calc` function we defined earlier. Its first argument is a function representing the operation, the second is the data to operate on, and the third is the initial value. Clearly, `reduce` is also a higher-order function. Together with `filter` and `map`, these three form the key operations in data processing: **filter**, **map**, and **reduce**.
>
> **Tip 2**: The lambda function for checking primes constructs a range from 2 to $\small{\sqrt{x}}$ using the `range` function and checks whether there are any factors of `x` in that range. The `all` function is also a Python built-in function — if all boolean values in the passed sequence are `True`, `all` returns `True`; otherwise it returns `False`.

### Partial Functions

A partial function is created by fixing some parameters of a function to produce a new function, so you don't have to pass the same arguments every time. In Python, we can use the `partial` function from the `functools` module to create partial functions. For example, the `int` function can convert a string treated as a decimal integer by default. By modifying its `base` parameter, we can define three new functions for converting binary, octal, and hexadecimal strings to integers, as shown below.

```python
import functools

int2 = functools.partial(int, base=2)
int8 = functools.partial(int, base=8)
int16 = functools.partial(int, base=16)

print(int('1001'))    # 1001

print(int2('1001'))   # 9
print(int8('1001'))   # 513
print(int16('1001'))  # 4097
```

Notice that the first parameter and the return value of `partial` are both functions — it takes an input function and returns a new function. By creating partial functions, we can transform original functions into more convenient new functions tailored to specific use cases. Quite an interesting trick, wouldn't you say?

###  Summary

Functions in Python are first-class functions — they can be assigned to variables, and they can serve as function parameters and return values. This means we can use higher-order functions in Python. The concept of higher-order functions is not beginner-friendly, but it brings great flexibility to function design. If a function we need to define is very simple, just one line of code, and we don't need a function name for reuse, we can use a lambda function.
