## Object Serialization and Deserialization

### JSON Overview

From the previous discussion, we already know how to save text data and binary data to files. But here's another question: what if we want to save data from a list or a dictionary to a file? In Python, we can save program data in JSON format. JSON stands for "JavaScript Object Notation." It was originally a literal syntax for creating objects in JavaScript, but it is now widely used for cross-language, cross-platform data exchange. The reason for using JSON is very simple: it is compact in structure and is plain text, and any operating system and programming language can handle plain text -- this is the prerequisite for **cross-language, cross-platform data exchange**. Currently, JSON has essentially replaced XML (Extensible Markup Language) as the **de facto standard for data exchange between heterogeneous systems**. You can find more information about JSON on the [official JSON website](https://www.json.org/json-zh.html), which also provides tools and third-party libraries for each language to handle JSON data.

```JavaScript
{
    name: "骆昊",
    age: 40,
    friends: ["王大锤", "白元芳"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

The above is a simple example of JSON. You may have already noticed that it is very similar to Python dictionaries and supports nested structures, just like how the value of a Python dictionary can be another dictionary. You can try entering the following code into your browser's console (for Chrome, you can find "Developer Tools" under the "More Tools" menu to open the browser console). The browser console provides an interactive environment for running JavaScript code (similar to Python's interactive environment). The code below will create a JavaScript object and assign it to a variable named `obj`.

```JavaScript
let obj = {
    name: "骆昊",
    age: 40,
    friends: ["王大锤", "白元芳"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

The `obj` above is an object in JavaScript. We can access the value corresponding to `name` using either `obj.name` or `obj["name"]`, as shown in the figure below. ### Reading and Writing JSON Data

In Python, to convert a dictionary to JSON format (as a string), you can use the `dumps` function from the `json` module, as shown below.

```python
import json

my_dict = {
    'name': '骆昊',
    'age': 40,
    'friends': ['王大锤', '白元芳'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
print(json.dumps(my_dict))
```

Running the code above produces the following output. Notice that Chinese characters are displayed using Unicode encoding.

```JSON
{"name": "\u9a86\u660a", "age": 40, "friends": ["\u738b\u5927\u9524", "\u767d\u5143\u82b3"], "cars": [{"brand": "BMW", "max_speed": 240}, {"brand": "Audi", "max_speed": 280}, {"brand": "Benz", "max_speed": 280}]}
```

To convert a dictionary to JSON format and write it to a text file, simply replace the `dumps` function with the `dump` function and pass in the file object, as shown below.

```python
import json

my_dict = {
    'name': '骆昊',
    'age': 40,
    'friends': ['王大锤', '白元芳'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
with open('data.json', 'w') as file:
    json.dump(my_dict, file)
```

Running the code above will create a `data.json` file with the same content as the output of the previous code.

The `json` module has four important functions:

- `dump` - Serializes a Python object to a file in JSON format
- `dumps` - Converts a Python object to a JSON-formatted string
- `load` - Deserializes JSON data from a file into an object
- `loads` - Deserializes the content of a string into a Python object

Here we encounter two concepts: serialization and deserialization. According to [Wikipedia](https://zh.wikipedia.org/): "Serialization in computer science is the process of translating a data structure or object state into a format that can be stored or transmitted, so that it can be reconstructed later. When the resulting series of bytes is reread according to the serialization format, it can be used to create a semantically identical clone of the original object. The reverse operation, extracting a data structure from a series of bytes, is deserialization."

We can use the following code to read the `data.json` file created above and restore the JSON-formatted data back to a Python dictionary.

```python
import json

with open('data.json', 'r') as file:
    my_dict = json.load(file)
    print(type(my_dict))
    print(my_dict)
```

### Package Management Tool pip

The `json` module in Python's standard library is not particularly ideal in terms of performance for data serialization and deserialization. To address this issue, you can use the third-party library `ujson` as a replacement for `json`. A third-party library refers to a Python module that is not developed and used internally by a company, nor comes from the official standard library. These modules are typically developed by other companies, organizations, or individuals, hence the name "third-party library." Although Python's standard library already provides numerous modules to facilitate development, a powerful language must also have a thriving ecosystem.

When installing the Python interpreter earlier, pip was installed by default. You can confirm whether you already have pip by typing `pip --version` in the command prompt or terminal. Pip is Python's package management tool. Through pip, you can find, install, uninstall, and update Python third-party libraries or tools. For example, to install `ujson` as a replacement for the `json` module, you can use the following command.

```Bash
pip install ujson
```

By default, pip accesses `https://pypi.org/simple/` to obtain third-party library data. However, access to this website from within China may not be ideal, so Chinese users can use mirrors provided by Douban or Tsinghua University to replace this default download source before installing third-party libraries. The commands are as follows.

```Bash
pip config set global.index-url https://pypi.doubanio.com/simple
pip install ujson
```

You can use the `pip search` command to find needed third-party libraries by name, and the `pip list` command to view already installed third-party libraries. To update a third-party library, use `pip install -U` or `pip install --upgrade`. To remove a third-party library, use the `pip uninstall` command.

### Using Web APIs to Fetch Data

If you want to display weather, traffic, flight, and other information in your own program, you can't provide this information yourself, so you must use web data services. Currently, the vast majority of web data services (also known as web APIs) provide JSON-formatted data over [HTTP](https://zh.wikipedia.org/wiki/%E8%B6%85%E6%96%87%E6%9C%AC%E4%BC%A0%E8%BE%93%E5%8D%8F%E8%AE%AE) or HTTPS. We can send an HTTP request from a Python program to a specified URL (Uniform Resource Locator) -- this URL is the so-called web API. If the request succeeds, it returns an HTTP response, and the body of the HTTP response contains the JSON-formatted data we need. For more about HTTP, you can read Ruan Yifeng's article [Introduction to HTTP Protocol](http://www.ruanyifeng.com/blog/2016/08/http.html).

There are many websites in China that provide web API interfaces, such as [Juhe Data](https://www.juhe.cn/), [Baidu AI Cloud](https://apis.baidu.com/), etc. These websites offer both free and paid data interfaces. The foreign website [{API}Search](http://apis.io/) also provides similar functionality for those interested. The following example demonstrates how to use the [`requests`](http://docs.python-requests.org/zh_CN/latest/) library (a third-party library for accessing web resources over HTTP) to access a web API to get domestic news and display the news titles and links. In this example, we use the domestic news data interface provided by the [Tianapi](https://www.tianapi.com/) website. The API Key (identity) needs to be obtained by registering on the website. After registering on the Tianapi website, an API Key is automatically assigned, but to access the interface and retrieve data, you need to verify your email or phone, and then apply for the interface you want to use, as shown below.

<img src="res/20210820151134.png" alt="image-20210820151134034" width="100%">

For Python to access the web via URLs, we recommend using the `requests` third-party library. It is simple and powerful, but needs to be installed separately.

```Bash
pip install requests
```

Get domestic news and display the news titles and links.

```python
import requests

resp = requests.get('http://api.tianapi.com/guonei/?key=APIKey&num=10')
if resp.status_code == 200:
    data_model = resp.json()
    for news in data_model['newslist']:
        print(news['title'])
        print(news['url'])
        print('-' * 60)
```

The code above uses the `get` function from the `requests` module to send a request to Tianapi's domestic news interface. If there are no issues with the request, the `get` function returns a `Response` object. The `status_code` attribute of this object represents the HTTP response status code. If you don't understand this, don't worry -- you just need to check its value. If the value equals `200` or any other value starting with `2`, then our request was successful. The `json()` method of the `Response` object can directly convert the returned JSON-formatted data into a Python dictionary, which is very convenient. The JSON-formatted data (partial) returned by Tianapi's domestic news interface is shown in the figure below.

> **Tip**: The `APIKey` in the code above needs to be replaced with the API Key you applied for on the Tianapi website. The Tianapi website also provides many interesting API interfaces, such as waste classification, dream interpretation, etc. You can follow the code above to call these interfaces. Each interface has corresponding documentation with detailed instructions on how to use it.

### Summary

In Python, besides using the `json` module for serialization and deserialization, you can also use the `pickle` and `shelve` modules. However, these two modules use proprietary serialization protocols, so the serialized data can only be recognized by Python. Interested readers can find related information about these two modules online. Being able to handle JSON-formatted data is clearly a skill that every programmer must master, because whether you're accessing web API interfaces or providing web API interfaces for others, you need to have knowledge of handling JSON-formatted data.
