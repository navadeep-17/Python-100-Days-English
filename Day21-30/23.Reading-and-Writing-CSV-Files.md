## Reading and Writing CSV Files in Python

### Introduction to CSV Files

CSV (Comma Separated Values) is a simple, universal file format that is widely used for importing and exporting data in applications (databases, spreadsheets, etc.) and for data exchange between heterogeneous systems. Since CSV is a plain text file, any operating system and programming language can handle plain text, and many programming languages provide support for reading and writing CSV files. Therefore, the CSV format is widely used in data processing and data science.

CSV files have the following characteristics:

1. Plain text, using a specific character set (such as [ASCII](https://zh.wikipedia.org/wiki/ASCII), [Unicode](https://zh.wikipedia.org/wiki/Unicode), [GB2312](https://zh.wikipedia.org/wiki/GB2312), etc.);
2. Composed of records (typically one record per line);
3. Each record is divided into fields (columns) by delimiters (such as commas, semicolons, tabs, etc.);
4. Every record has the same sequence of fields.

CSV files can be opened and edited with text editors or tools like Excel spreadsheets. When you open a CSV file with a spreadsheet application like Excel, you can hardly tell the difference between CSV and Excel files. Many database systems support exporting data to CSV files and importing data from CSV files into databases, but these topics are not the focus of our current discussion.

### Writing Data to a CSV File

Suppose we have the exam scores of five students in three courses that need to be saved to a CSV file. To achieve this, we can use the `csv` module from Python's standard library. The `writer` function of this module returns a `csvwriter` object, and through this object's `writerow` or `writerows` methods, we can write data to a CSV file. The specific code is shown below.

```python
import csv
import random

with open('scores.csv', 'w') as file:
    writer = csv.writer(file)
    writer.writerow(['Name', 'Chinese', 'Math', 'English'])
    names = ['Guan Yu', 'Zhang Fei', 'Zhao Yun', 'Ma Chao', 'Huang Zhong']
    for name in names:
        scores = [random.randrange(50, 101) for _ in range(3)]
        scores.insert(0, name)
        writer.writerow(scores)
```

The content of the generated CSV file.

```
Name,Chinese,Math,English
Guan Yu,98,86,61
Zhang Fei,86,58,80
Zhao Yun,95,73,70
Ma Chao,83,97,55
Huang Zhong,61,54,87
```

It should be noted that the `writer` function above, in addition to the file object to write data to, can also accept a `dialect` parameter, which represents the CSV file's dialect and defaults to `excel`. Additionally, you can use the `delimiter`, `quotechar`, and `quoting` parameters to specify the delimiter (default is comma), the character used to enclose values (default is double quotes), and the quoting style. The enclosing character is mainly used when a field contains special symbols -- adding the enclosing character can avoid ambiguity. You can try modifying line 5 of the code above to the following, and then check the generated CSV file.

```python
writer = csv.writer(file, delimiter='|', quoting=csv.QUOTE_ALL)
```

The content of the generated CSV file.

```
"Name"|"Chinese"|"Math"|"English"
"Guan Yu"|"88"|"64"|"65"
"Zhang Fei"|"76"|"93"|"79"
"Zhao Yun"|"78"|"55"|"76"
"Ma Chao"|"72"|"77"|"68"
"Huang Zhong"|"70"|"72"|"51"
```

### Reading Data from a CSV File

To read the CSV file we just created, you can use the following code. The `reader` function from the `csv` module creates a `csvreader` object, which is an iterator. You can use the `next` function or a `for-in` loop to read data from the file.

```python
import csv

with open('scores.csv', 'r') as file:
    reader = csv.reader(file, delimiter='|')
    for data_list in reader:
        print(reader.line_num, end='\t')
        for elem in data_list:
            print(elem, end='\t')
        print()
```

> **Note**: When iterating over the `csvreader` object with a `for` loop, each iteration yields a list object containing all the fields in one row.

### Summary

In the future, if you use Python for data analysis, you will very likely use a third-party library called `pandas`, which is one of the most powerful tools for Python data analysis. `pandas` provides functions called `read_csv` and `to_csv` for reading and writing CSV files. `read_csv` converts the read data into a `DataFrame` object, and `DataFrame` is the most important type in the `pandas` library -- it provides a series of methods for data processing (cleaning, transformation, aggregation, etc.). `to_csv` writes the data from a `DataFrame` object to a CSV file, achieving data persistence. The `read_csv` and `to_csv` functions are far more powerful than the native `csvreader` and `csvwriter`.
