## Reading and Writing Excel Files in Python - Part 1

### Introduction to Excel

Excel is a spreadsheet software developed by Microsoft for the Windows and macOS operating systems. With its intuitive interface, excellent computation capabilities, and charting tools, combined with successful marketing, Excel has long been the most popular personal computer data processing software. Of course, Excel has many competitors, such as Google Sheets, LibreOffice Calc, Numbers, etc. These competitors are basically compatible with Excel and can at least read and write newer versions of Excel files, but these are not the focus of our discussion. Mastering how to manipulate Excel files with Python programs can make daily office automation tasks much easier and more enjoyable. Moreover, importing and exporting Excel files is a very common feature in many commercial projects.

Working with Excel in Python requires third-party library support. If you need compatibility with Excel versions prior to 2007, i.e., `xls` format Excel files, you can use the third-party libraries `xlrd` and `xlwt` -- the former is for reading Excel files, and the latter is for writing Excel files. If you use newer versions of Excel, i.e., `xlsx` format Excel files, you can use the `openpyxl` library, which can not only work with Excel but also with other spreadsheet files based on Office Open XML.

In this chapter, we will first explain how to work with Excel files using `xlwt` and `xlrd`. You can install these two third-party libraries along with the utility module `xlutils` using the following command.

```Bash
pip install xlwt xlrd xlutils
```

### Reading Excel Files

For example, suppose there is an Excel file named "Alibaba 2020 Stock Data.xls" in the current folder. If you want to read and display the contents of this file, you can do so with the following code.

```python
import xlrd

# Use the open_workbook function of the xlrd module to open the specified Excel file and get a Book object (workbook)
wb = xlrd.open_workbook('阿里巴巴2020年股票数据.xls')
# Get all sheet names through the Book object's sheet_names method
sheetnames = wb.sheet_names()
print(sheetnames)
# Get a Sheet object (worksheet) by the specified sheet name
sheet = wb.sheet_by_name(sheetnames[0])
# Get the number of rows and columns through the Sheet object's nrows and ncols attributes
print(sheet.nrows, sheet.ncols)
for row in range(sheet.nrows):
    for col in range(sheet.ncols):
        # Get the specified Cell object through the Sheet object's cell method
        # Get the value in the cell through the Cell object's value attribute
        value = sheet.cell(row, col).value
        # Format data for all rows except the header row
        if row > 0:
            # Convert the xldate type in column 1 to a tuple first, then format as "Year-Month-Day"
            if col == 0:
                # The second parameter of xldate_as_tuple only has two values: 0 and 1
                # 0 represents dates based on 1900-01-01, 1 represents dates based on 1904-01-01
                value = xlrd.xldate_as_tuple(value, 0)
                value = f'{value[0]}年{value[1]:>02d}月{value[2]:>02d}日'
            # Format other columns' number types as floats with two decimal places
            else:
                value = f'{value:.2f}'
        print(value, end='\t')
    print()
# Get the data type of the last cell
# 0 - empty, 1 - string, 2 - number, 3 - date, 4 - boolean, 5 - error
last_cell_type = sheet.cell_type(sheet.nrows - 1, sheet.ncols - 1)
print(last_cell_type)
# Get the values of the first row (as a list)
print(sheet.row_values(0))
# Get data for a specified row within a specified column range (as a list)
# The first parameter is the row index, the second and third parameters are the start (inclusive) and end (exclusive) column indices
print(sheet.row_slice(3, 0, 5))
```

> **Tip**: The Excel file "Alibaba 2020 Stock Data.xls" used in the code above can be obtained from the following Baidu Cloud link: https://pan.baidu.com/s/1rQujl5RQn9R7PadB2Z5g_g, access code: e7b4.

With the code above, you should now understand how to read an Excel file. If you want to learn more about the `xlrd` module, you can read its [official documentation](https://xlrd.readthedocs.io/en/latest/).

### Writing Excel Files

To write to an Excel file, you can create a workbook object using the `Workbook` class from the `xlwt` module. Through the workbook object's `add_sheet` method, you can add worksheets. Through the worksheet object's `write` method, you can write data to specified cells. Finally, through the workbook object's `save` method, you can save the workbook to a specified file or memory. The following code writes the exam scores of 5 students in 3 courses to an Excel file.

```python
import random

import xlwt

student_names = ['Guan Yu', 'Zhang Fei', 'Zhao Yun', 'Ma Chao', 'Huang Zhong']
scores = [[random.randrange(50, 101) for _ in range(3)] for _ in range(5)]
# Create a Workbook object
wb = xlwt.Workbook()
# Create a Worksheet object
sheet = wb.add_sheet('Grade 1 Class 2')
# Add header data
titles = ('Name', 'Chinese', 'Math', 'English')
for index, title in enumerate(titles):
    sheet.write(0, index, title)
# Write student names and exam scores to cells
for row in range(len(scores)):
    sheet.write(row + 1, 0, student_names[row])
    for col in range(len(scores[row])):
        sheet.write(row + 1, col + 1, scores[row][col])
# Save the Excel workbook
wb.save('exam_scores.xls')
```

### Adjusting Cell Styles

When writing Excel files, we can also set styles for cells, mainly including font (Font), alignment (Alignment), border (Border), and background (Background) settings. `xlwt` provides corresponding classes to support each of these settings. To set a cell style, you first need to create an `XFStyle` object, and then configure the font, alignment, border, etc. through the object's attributes. For example, in the above example, if you want to change the header cell background color to yellow, you can do it as follows.

```python
header_style = xlwt.XFStyle()
pattern = xlwt.Pattern()
pattern.pattern = xlwt.Pattern.SOLID_PATTERN
# 0 - black, 1 - white, 2 - red, 3 - green, 4 - blue, 5 - yellow, 6 - pink, 7 - cyan
pattern.pattern_fore_colour = 5
header_style.pattern = pattern
titles = ('Name', 'Chinese', 'Math', 'English')
for index, title in enumerate(titles):
    sheet.write(0, index, title, header_style)
```

If you want to set a specific font for the header, you can use the `Font` class and add the following code.

```python
font = xlwt.Font()
# Font name
font.name = '华文楷体'
# Font size (20 is the base unit, 18 means 18px)
font.height = 20 * 18
# Whether to use bold
font.bold = True
# Whether to use italic
font.italic = False
# Font color
font.colour_index = 1
header_style.font = font
```

> **Note**: The font name specified in the code above (`font.name`) should be a font that exists on the local system. For example, my computer has a font called "华文楷体" (STKaiti).

If you want the header to be vertically centered, you can use the following code.

```python
align = xlwt.Alignment()
# Vertical alignment
align.vert = xlwt.Alignment.VERT_CENTER
# Horizontal alignment
align.horz = xlwt.Alignment.HORZ_CENTER
header_style.alignment = align
```

If you want to add a yellow dashed border to the header, you can use the following code.

```python
borders = xlwt.Borders()
props = (
    ('top', 'top_colour'), ('right', 'right_colour'),
    ('bottom', 'bottom_colour'), ('left', 'left_colour')
)
# Set the border style and color for all four directions through a loop
for position, color in props:
    # Use the built-in setattr function to dynamically assign values to the object's specified attributes
    setattr(borders, position, xlwt.Borders.DASHED)
    setattr(borders, color, 5)
header_style.borders = borders
```

To adjust the cell width (column width) and header height (row height), you can use the following code.

```python
# Set row height to 40px
sheet.row(0).set_style(xlwt.easyxf(f'font:height {20 * 40}'))
titles = ('Name', 'Chinese', 'Math', 'English')
for index, title in enumerate(titles):
    # Set column width to 200px
    sheet.col(index).width = 20 * 200
    # Set the cell data and style
    sheet.write(0, index, title, header_style)
```

### Formula Calculations

For the previously opened "Alibaba 2020 Stock Data.xls" file, if you want to calculate the annual average closing price (Close field) and the total annual trading volume (Volume field), you can use Excel formulas. We can first read the Excel file using `xlrd`, then convert it to a `Workbook` object for writing operations using the `copy` function provided by the `xlutils` third-party library. When calling the `write` method, you can write a `Formula` object to a cell.

The code for implementing formula calculations is shown below.

```python
import xlrd
import xlwt
from xlutils.copy import copy

wb_for_read = xlrd.open_workbook('阿里巴巴2020年股票数据.xls')
sheet1 = wb_for_read.sheet_by_index(0)
nrows, ncols = sheet1.nrows, sheet1.ncols
wb_for_write = copy(wb_for_read)
sheet2 = wb_for_write.get_sheet(0)
sheet2.write(nrows, 4, xlwt.Formula(f'average(E2:E{nrows})'))
sheet2.write(nrows, 6, xlwt.Formula(f'sum(G2:G{nrows})'))
wb_for_write.save('阿里巴巴2020年股票数据汇总.xls')
```
