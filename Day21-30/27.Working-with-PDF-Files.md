## Working with PDF Files in Python

PDF stands for Portable Document Format, and these files typically use `.pdf` as their extension. In daily development work, the most common tasks involving PDF are extracting text content from PDFs and generating PDF documents from existing content.

### Extracting Text from PDFs

In Python, you can use the third-party library `PyPDF2` to read PDF files. You can install it using the following command.

```Bash
pip install PyPDF2
```

`PyPDF2` cannot extract images, charts, or other media from PDF documents, but it can extract text and return it as Python strings.

```python
import PyPDF2

reader = PyPDF2.PdfReader('test.pdf')
for page in reader.pages:
    print(page.extract_text())
```

### Rotating and Overlaying Pages

In the code above, we read the PDF document by creating a `PdfFileReader` object. The object's `getPage` method retrieves a specific page from the PDF document as a `PageObject`. Through the `PageObject`'s `rotateClockwise` and `rotateCounterClockwise` methods, you can rotate pages clockwise and counterclockwise. Through the `PageObject`'s `addBlankPage` method, you can add a new blank page. The code is shown below.

```python
reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for no, page in enumerate(reader.pages):
    if no % 2 == 0:
        new_page = page.rotate(-90)
    else:
        new_page = page.rotate(90)
    writer.add_page(new_page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Encrypting PDF Files

Using the `PdfFileWriter` object in `PyPDF2`, you can encrypt PDF documents. If you need to set a uniform access password for a series of PDF documents, using a Python program to handle this is very convenient.

```python
import PyPDF2

reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for page in reader.pages:
    writer.add_page(page)

writer.encrypt('foobared')

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Batch Adding Watermarks

The `PageObject` mentioned above also has a method called `mergePage` that can overlay two PDF pages. Through this operation, we can easily add watermarks to PDF files. For example, to add a watermark to the "XGBoost.pdf" file above, we can first prepare a PDF file that provides the watermark page, then read the watermark `PageObject`, and then iterate through each page of the "XGBoost.pdf" file to get the `PageObject` and use the `mergePage` method to merge the watermark page with the original page. The code is shown below.

```python
reader1 = PyPDF2.PdfReader('XGBoost.pdf')
reader2 = PyPDF2.PdfReader('watermark.pdf')
writer = PyPDF2.PdfWriter()
watermark_page = reader2.pages[0]

for page in reader1.pages:
    page.merge_page(watermark_page)
    writer.add_page(page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

If you'd like, you can even use different watermarks for odd and even pages. Think about how you would implement that on your own.

### Creating PDF Files

Creating PDF documents requires support from the third-party library `reportlab`. The installation method is shown below.

```Bash
pip install reportlab
```

Below is an example to demonstrate the usage of `reportlab`.

```python
from reportlab.lib.pagesizes import A4
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.pdfgen import canvas

pdf_canvas = canvas.Canvas('resources/demo.pdf', pagesize=A4)
width, height = A4

# Draw an image
image = canvas.ImageReader('resources/guido.jpg')
pdf_canvas.drawImage(image, 20, height - 395, 250, 375)

# Show the current page
pdf_canvas.showPage()

# Register font files
pdfmetrics.registerFont(TTFont('Font1', 'resources/fonts/Vera.ttf'))
pdfmetrics.registerFont(TTFont('Font2', 'resources/fonts/青呱石头体.ttf'))

# Write text
pdf_canvas.setFont('Font2', 40)
pdf_canvas.setFillColorRGB(0.9, 0.5, 0.3, 1)
pdf_canvas.drawString(width // 2 - 120, height // 2, '你好，世界！')
pdf_canvas.setFont('Font1', 40)
pdf_canvas.setFillColorRGB(0, 1, 0, 0.5)
pdf_canvas.rotate(18)
pdf_canvas.drawString(250, 250, 'hello, world!')

# Save
pdf_canvas.save()
```

Don't worry if the code above is not entirely clear. When you actually need to create PDF documents with Python, you can study the `reportlab` [official documentation](https://www.reportlab.com/docs/reportlab-userguide.pdf) in detail.
