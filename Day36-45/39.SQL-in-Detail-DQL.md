## SQL in Detail - DQL

Next, we will use the school course selection system database created earlier to explain query operations in DML. Whether you are a developer or a data analyst, queries are extremely important as they determine whether we can retrieve the data we need from a relational database. It is recommended that you re-execute the DDL for creating the database and tables from two lessons ago, as well as the DML for inserting data from the previous lesson, to ensure that the tables and data are correct before performing the operations below.

```SQL
USE school;

-- Query all information of all students
SELECT stu_id,
       stu_name,
       stu_sex,
       stu_birth,
       stu_addr,
       col_id
  FROM tb_student;

-- Query student ID, name, and hometown (projection and aliases)
SELECT stu_id AS student_id,
       stu_name AS name,
       stu_addr AS hometown
  FROM tb_student;

-- Query names and credits of all courses (projection and aliases)
SELECT cou_name AS course_name,
       cou_credit AS credits
  FROM tb_course;

-- Query names and dates of birth of all female students (data filtering)
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 0;

-- Query names and dates of birth of female students from "四川成都" (data filtering)
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 0
       AND stu_addr = '四川成都';

-- Query students from "四川成都" or female students (data filtering)
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 0
       OR stu_addr = '四川成都';

-- Query names, gender, and dates of birth of all students born in the 1980s (data filtering)
SELECT stu_name,
       stu_sex,
       stu_birth
  FROM tb_student
 WHERE '1980-1-1' <= stu_birth
       AND stu_birth <= '1989-12-31';

SELECT stu_name,
       stu_sex,
       stu_birth
  FROM tb_student
 WHERE stu_birth BETWEEN '1980-1-1' AND '1989-12-31';

-- Query names and credits of courses with more than 2 credits (data filtering)
SELECT cou_name,
	   cou_credit
  FROM tb_course
 WHERE cou_credit > 2;

-- Query names and credits of courses with odd number of credits (data filtering)
SELECT cou_name,
	   cou_credit
  FROM tb_course
 WHERE cou_credit MOD 2 <> 0;

-- Query student IDs of students who scored above 90 in course 1111 (data filtering)
SELECT stu_id
  FROM tb_record
 WHERE cou_id = 1111
       AND score > 90;

-- Query name and gender of the student named "杨过" (data filtering)
SELECT stu_name AS name,
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS gender
  FROM tb_student
 WHERE stu_name = '杨过';

SELECT stu_name AS name,
       IF(stu_sex, 'Male', 'Female') AS gender
  FROM tb_student
 WHERE stu_name = '杨过';

-- Query names and gender of students with surname "杨" (fuzzy matching)
-- Wildcard % matches zero or any number of characters
SELECT stu_name AS name,
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS gender
  FROM tb_student
 WHERE stu_name LIKE '杨%';

-- Query names and gender of students with surname "杨" and a two-character name (fuzzy matching)
-- Wildcard _ matches exactly one character
SELECT stu_name AS name,
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS gender
  FROM tb_student
 WHERE stu_name LIKE '杨_';

-- Query names and gender of students with surname "杨" and a three-character name (fuzzy matching)
SELECT stu_name AS name,
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS gender
  FROM tb_student
 WHERE stu_name LIKE '杨__';

-- Query student IDs and names of students whose ID ends with 3 (fuzzy matching)
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_id LIKE '%3';

-- Query student IDs and names of students with "不" or "嫣" in their name (fuzzy matching and union)
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name LIKE '%不%'
       OR stu_name LIKE '%嫣%';

SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name LIKE '%不%'
 UNION
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name LIKE '%嫣%';

-- Query student IDs and names of students with surname "杨" or "林" and a three-character name (regex fuzzy matching)
SELECT stu_id,
       stu_name
  FROM tb_student
 WHERE stu_name REGEXP '[林杨][\\u4e00-\\u9fa5]{2}';

-- Query names of students without a hometown recorded (null value handling)
SELECT stu_name
  FROM tb_student
 WHERE TRIM(stu_addr) = ''
       OR stu_addr is null;

-- Query names of students with a hometown recorded (null value handling)
SELECT stu_name
  FROM tb_student
 WHERE TRIM(stu_addr) <> ''
       AND stu_addr is not null;

-- Query all course selection dates (deduplication)
SELECT DISTINCT sel_date
  FROM tb_record;

-- Query student hometowns (deduplication)
SELECT DISTINCT stu_addr
  FROM tb_student
 WHERE TRIM(stu_addr) <> ''
       AND stu_addr is not null;

-- Query names and dates of birth of male students sorted by age from oldest to youngest (sorting)
SELECT stu_name,
       stu_birth
  FROM tb_student
 WHERE stu_sex = 1
 ORDER BY stu_birth ASC;

-- Supplement: Convert dates of birth to ages (date functions, numeric functions)
SELECT stu_name AS name,
       FLOOR(DATEDIFF(CURDATE(), stu_birth) / 365) AS age
  FROM tb_student
 WHERE stu_sex = 1
 ORDER BY age DESC;

-- Query the date of birth of the oldest student (aggregate function)
SELECT MIN(stu_birth)
  FROM tb_student;

-- Query the date of birth of the youngest student (aggregate function)
SELECT MAX(stu_birth)
  FROM tb_student;

-- Query the highest score for course 1111 (aggregate function)
SELECT MAX(score)
  FROM tb_record
 WHERE cou_id = 1111;

-- Query minimum score, maximum score, average score, standard deviation, and variance for student 1001 (aggregate functions)
SELECT MIN(score) AS min_score,
       MAX(score) AS max_score,
	   ROUND(AVG(score), 1) AS avg_score,
       STDDEV(score) AS std_dev,
       VARIANCE(score) AS variance
  FROM tb_record
 WHERE stu_id = 1001;

-- Query the average score for student 1001, treating NULL values as 0 (aggregate functions)
SELECT ROUND(SUM(score) / COUNT(*), 1) AS avg_score
  FROM tb_record
 WHERE stu_id = 1001;

-- Query the number of male and female students (grouping and aggregate functions)
SELECT CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS gender,
       COUNT(*) AS count
  FROM tb_student
 GROUP BY stu_sex;

-- Query the number of students in each college (grouping and aggregate functions)
SELECT col_id AS college_id,
       COUNT(*) AS count
  FROM tb_student
 GROUP BY col_id
  WITH ROLLUP;

-- Query the number of male and female students in each college (grouping and aggregate functions)
SELECT col_id AS college_id,
       CASE stu_sex WHEN 1 THEN 'Male' ELSE 'Female' END AS gender,
       COUNT(*) AS count
  FROM tb_student
 GROUP BY col_id, stu_sex;

-- Query student IDs and average scores for each student (grouping and aggregate functions)
SELECT stu_id AS student_id,
	   ROUND(AVG(score), 1) AS avg_score
  FROM tb_record
 GROUP BY stu_id;

-- Query student IDs and average scores for students with average score >= 90 (filtering after grouping)
SELECT stu_id AS student_id,
	   ROUND(AVG(score), 1) AS avg_score
  FROM tb_record
 GROUP BY stu_id
HAVING avg_score >= 90;

-- Query student IDs and average scores for students with average score >= 90 in courses 1111, 2222, 3333 (filtering before and after grouping)
SELECT stu_id AS student_id,
	   ROUND(AVG(score), 1) AS avg_score
  FROM tb_record
 WHERE cou_id in (1111, 2222, 3333)
 GROUP BY stu_id
HAVING avg_score >= 90
 ORDER BY avg_score ASC;

-- Query the name of the oldest student (subquery)
SELECT stu_name
  FROM tb_student
 WHERE stu_birth = (SELECT MIN(stu_birth)
                      FROM tb_student);

-- Query names of students who selected more than two courses (subquery and set operation)
SELECT stu_name
  FROM tb_student
 WHERE stu_id in (SELECT stu_id
				    FROM tb_record
				   GROUP BY stu_id
				  HAVING COUNT(*) > 2);

-- Query student names, dates of birth, and college names (table join)
SELECT stu_name,
       stu_birth,
       col_name
  FROM tb_student AS t1, tb_college AS t2
 WHERE t1.col_id = t2.col_id;

SELECT stu_name,
       stu_birth,
	   col_name
  FROM tb_student INNER JOIN tb_college
       ON tb_student.col_id = tb_college.col_id;

SELECT stu_name,
       stu_birth,
	   col_name
  FROM tb_student NATURAL JOIN tb_college;

SELECT stu_name,
       stu_birth,
	   col_name
  FROM tb_student CROSS JOIN tb_college;

-- Query student names, course names, and scores (table join)
SELECT stu_name,
       cou_name,
	   score
  FROM tb_student, tb_course, tb_record
 WHERE tb_student.stu_id = tb_record.stu_id
       AND tb_course.cou_id = tb_record.cou_id
       AND score is not null;

SELECT stu_name,
       cou_name,
	   score
  FROM tb_student
       INNER JOIN tb_record
	       ON tb_student.stu_id = tb_record.stu_id
	   INNER JOIN tb_course
	       ON tb_course.cou_id = tb_record.cou_id
 WHERE score is not null;

SELECT stu_name,
       cou_name,
       score
  FROM tb_student
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null;

-- Supplement: Get the first 5 rows of the above query results (pagination)
SELECT stu_name,
       cou_name,
       score
  FROM tb_student
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null
 ORDER BY cou_id ASC, score DESC
 LIMIT 5;

-- Supplement: Get rows 6-10 of the above query results (pagination)
SELECT stu_name,
       cou_name,
       score
  FROM tb_student
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null
 ORDER BY cou_id ASC, score DESC
 LIMIT 5
OFFSET 5;

-- Supplement: Get rows 11-15 of the above query results (pagination)
SELECT stu_name,
       cou_name,
       score
  FROM tb_student
	   NATURAL JOIN tb_record
       NATURAL JOIN tb_course
 WHERE score is not null
 ORDER BY cou_id ASC, score DESC
 LIMIT 10, 5;

-- Query student names and average scores for students who selected courses (subquery and table join)
-- Error Code: 1248. Every derived table must have its own alias
SELECT stu_name,
	   avg_score
  FROM tb_student
       NATURAL JOIN (SELECT stu_id,
                            ROUND(AVG(score), 1) AS avg_score
                       FROM tb_record
                      GROUP BY stu_id) as tmp;

-- Query student names and the number of courses selected (subquery and table join)
SELECT stu_name,
	   total
  FROM tb_student
       NATURAL JOIN (SELECT stu_id,
                            COUNT(*) AS total
                       FROM tb_record
                      GROUP BY stu_id) as tmp;

-- Query each student's name and number of courses selected (subquery and left outer join)
SELECT stu_name AS name,
	   COALESCE(total, 0) AS courses_selected
  FROM tb_student AS t1
	   LEFT JOIN (SELECT stu_id,
			             COUNT(*) AS total
		            FROM tb_record
				   GROUP BY stu_id) AS t2
	       ON t1.stu_id = t2.stu_id;
```

There are several points that need explanation:

1. MySQL currently does not support full outer joins. Above we use a `union` operation to combine the results of a left outer join and a right outer join to achieve the effect of a full outer join. You can use the diagram below to deepen your understanding of join operations.

2. MySQL supports multiple types of operators, including: arithmetic operators (`+`, `-`, `*`, `/`, `%`), comparison operators (`=`, `<>`, `<=>`, `<`, `<=`, `>`, `>=`, `BETWEEN...AND...`, `IN`, `IS NULL`, `IS NOT NULL`, `LIKE`, `RLIKE`, `REGEXP`), logical operators (`NOT`, `AND`, `OR`, `XOR`), and bitwise operators (`&`, `|`, `^`, `~`, `>>`, `<<`). We can use these operators in DML to process data.

3. When querying data, functions can be used in `SELECT` statements and their clauses (such as `WHERE`, `ORDER BY`, `HAVING` clauses, etc.). These functions include string functions, numeric functions, date/time functions, flow control functions, etc., as shown in the tables below.

   Common String Functions.

   | Function                    | Description                                                  |
   | --------------------------- | ------------------------------------------------------------ |
   | `CONCAT`                    | Concatenate multiple strings into one string                 |
   | `FORMAT`                    | Format a number as a string with a specified number of decimal places |
   | `FROM_BASE64` / `TO_BASE64` | BASE64 decoding/encoding                                     |
   | `BIN` / `OCT` / `HEX`       | Convert a number to binary/octal/hexadecimal string          |
   | `LOCATE`                    | Find the position of a substring within a string             |
   | `LEFT` / `RIGHT`            | Return a specified number of characters from the left/right of a string |
   | `LENGTH` / `CHAR_LENGTH`    | Return the length of a string in bytes/characters            |
   | `LOWER` / `UPPER`           | Return the lowercase/uppercase form of a string              |
   | `LPAD` / `RPAD`             | Pad the left/right side of a string with specified characters if its length is insufficient |
   | `LTRIM` / `RTRIM`           | Remove leading/trailing spaces from a string                 |
   | `ORD` / `CHAR`              | Return the code for a character / return the character for a code |
   | `STRCMP`                    | Compare strings, returning -1, 0, 1 for less than, equal to, greater than |
   | `SUBSTRING`                 | Return a substring from a specified range                    |

   Common Numeric Functions.

   | Function                                                     | Description                                    |
   | -------------------------------------------------------- | ---------------------------------- |
   | `ABS`                                                    | Return the absolute value of a number          |
   | `CEILING` / `FLOOR`                                      | Return the ceiling/floor of a number           |
   | `CONV`                                                   | Convert a number from one base to another      |
   | `CRC32`                                                  | Compute cyclic redundancy check value          |
   | `EXP` / `LOG` / `LOG2` / `LOG10`                         | Compute exponential/logarithm                  |
   | `POW`                                                    | Compute power                                  |
   | `RAND`                                                   | Return a random number in [0,1)                |
   | `ROUND`                                                  | Return a number rounded to the nearest integer |
   | `SQRT`                                                   | Return the square root of a number             |
   | `TRUNCATE`                                               | Truncate a number to a specified precision      |
   | `SIN` / `COS` / `TAN` / `COT` / `ASIN` / `ACOS` / `ATAN` | Trigonometric functions                        |

   Common Date/Time Functions.

   | Function                                      | Description                                   |
   | ----------------------------------------- | ------------------------------------- |
   | `CURDATE` / `CURTIME` / `NOW`             | Get current date/time/date and time           |
   | `ADDDATE` / `SUBDATE`                     | Add/subtract two date expressions and return result |
   | `DATE` / `TIME`                           | Extract date/time from a string               |
   | `YEAR` / `MONTH` / `DAY`                  | Extract year/month/day from a date            |
   | `HOUR` / `MINUTE` / `SECOND`              | Extract hour/minute/second from a time        |
   | `DATEDIFF` / `TIMEDIFF` / `TIMESTAMPDIFF` | Return the difference between two date/time expressions in days/hours |
   | `MAKEDATE` / `MAKETIME`                   | Construct a date/time                         |

   Common Flow Control Functions.

   | Function | Description                                             |
   | -------- | ------------------------------------------------------- |
   | `IF`     | Return different values based on whether a condition is true |
   | `IFNULL` | Return a specified value if NULL, otherwise return itself |
   | `NULLIF` | Return NULL if two expressions are equal, otherwise return the first expression's value |

   Other Common Functions.

   | Function                     | Description                          |
   | -------------------------- | ----------------------------- |
   | `MD5` / `SHA1` / `SHA2`    | Return the hash digest of a string   |
   | `CHARSET` / `COLLATION`    | Return the character set/collation   |
   | `USER` / `CURRENT_USER`    | Return the current user              |
   | `DATABASE`                 | Return the current database name     |
   | `VERSION`                  | Return the current database version  |
   | `FOUND_ROWS` / `ROW_COUNT` | Return the number of rows found/affected |
   | `LAST_INSERT_ID`           | Return the last auto-increment primary key value |
   | `UUID` / `UUID_SHORT`      | Return a globally unique identifier  |
