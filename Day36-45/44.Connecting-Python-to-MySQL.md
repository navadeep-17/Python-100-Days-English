## Connecting Python to MySQL Database

In Python 3, we can use the `mysqlclient` or `pymysql` third-party libraries to connect to MySQL databases and perform data persistence operations. Both have identical usage, differing only in the imported module name. We recommend using the pure Python third-party library `pymysql` because it is easier to install successfully. Below, we will continue to use the database named `hrs` created earlier to demonstrate how to operate a MySQL database through Python programs for data persistence.

### Connecting to MySQL

First, we can install `pymysql` via the command line or PyCharm's terminal using the command below. If you need to connect to MySQL 8, you also need to install a third-party library called `cryptography` to support MySQL 8's password authentication method.

```Shell
pip install pymysql cryptography
```

The steps for using `pymysql` to operate MySQL are as follows:

1. Create a connection. After the MySQL server starts, it provides a network service based on TCP (Transmission Control Protocol). We can use the `connect` function of the `pymysql` module to connect to the MySQL server. When calling the `connect` function, you need to specify parameters such as host (`host`), port (`port`), username (`user`), password (`password`), database (`database`), character set (`charset`), etc. This function returns a `Connection` object.
2. Get a cursor. After successfully connecting to the MySQL server, the next step is to send SQL statements to the database server. MySQL will execute the received SQL and return the results over the network. To accomplish this, you first need to obtain a cursor (`Cursor`) object through the connection object's `cursor` method.
3. Send SQL. Through the cursor object's `execute` method, we can send SQL statements to the database.
4. If executing `insert`, `delete`, or `update` operations, you need to commit or rollback the transaction as appropriate. Because a transaction environment is enabled by default when creating a connection, after the operation is complete, you need to use the connection object's `commit` or `rollback` method to commit or rollback the transaction. The `rollback` method is typically placed in the `except` exception handling block. If executing a `select` operation, you need to fetch the query results through the cursor object. There are three corresponding methods: `fetchone`, `fetchmany`, and `fetchall`. The `fetchone` method fetches one record and returns it as a tuple or dictionary; `fetchmany` and `fetchall` methods fetch multiple records and return them as nested tuples or lists of dictionaries.
5. Close the connection. After completing persistence operations, do not forget to close the connection to release external resources. We typically use the connection object's `close` method in a `finally` block to close the connection.

### Hands-on Practice

Below, we demonstrate the five steps mentioned above through hands-on coding.

#### Inserting Data

```Python
import pymysql

no = int(input('Department number: '))
name = input('Department name: ')
location = input('Department location: ')

# 1. Create a connection (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Get a cursor object (Cursor)
    with conn.cursor() as cursor:
        # 3. Send SQL statement to the database server via cursor object
        affected_rows = cursor.execute(
            'insert into `tb_dept` values (%s, %s, %s)',
            (no, name, location)
        )
        if affected_rows == 1:
            print('New department added successfully!!!')
    # 4. Commit the transaction
    conn.commit()
except pymysql.MySQLError as err:
    # 4. Rollback the transaction
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Close the connection and release resources
    conn.close()
```

> **Note**: The `127.0.0.1` above is called the loopback address, which represents the local machine. The `guest` below is a user I created in advance, which has `insert`, `delete`, `update`, and `select` permissions on the `hrs` database. We do not recommend using the `root` superadmin account directly in projects to access the database, as this is too dangerous. We can use the following commands to create a user named `guest` and grant permissions.
>
> ```SQL
> create user 'guest'@'%' identified by 'Guest.618';
> grant insert, delete, update, select on `hrs`.* to 'guest'@'%';
> ```

If you need to insert a large amount of data, it is recommended to use the cursor object's `executemany` method for batch processing (a single `insert` operation followed by multiple sets of data). You can try inserting 10,000 records into a table and see the difference between inserting them one by one without batch processing and using batch processing. The `executemany` method's first parameter is still the SQL statement, and the second parameter can be a list or tuple containing multiple sets of data.

#### Deleting Data

```Python
import pymysql

no = int(input('Department number: '))

# 1. Create a connection (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4',
                       autocommit=True)
try:
    # 2. Get a cursor object (Cursor)
    with conn.cursor() as cursor:
        # 3. Send SQL statement to the database server via cursor object
        affected_rows = cursor.execute(
            'delete from `tb_dept` where `dno`=%s',
            (no, )
        )
        if affected_rows == 1:
            print('Department deleted successfully!!!')
finally:
    # 5. Close the connection and release resources
    conn.close()
```

> **Note**: If you do not want to manually commit or rollback transactions after each SQL operation, you can add a parameter named `autocommit` to the `connect` function and set its value to `True`, which means each successful SQL execution will be automatically committed. However, we recommend manual commit or rollback, as this allows you to construct transaction environments based on actual business needs. If you do not want to catch exceptions and handle them, you can follow the `try` block directly with a `finally` block. Omitting `except` means that when an exception occurs, the code will crash directly and display the exception stack in the terminal.

#### Updating Data

```Python
import pymysql

no = int(input('Department number: '))
name = input('Department name: ')
location = input('Department location: ')

# 1. Create a connection (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Get a cursor object (Cursor)
    with conn.cursor() as cursor:
        # 3. Send SQL statement to the database server via cursor object

            'update `tb_dept` set `dname`=%s, `dloc`=%s where `dno`=%s',

        )

            print('Department information updated successfully!!!')

    conn.commit()
except pymysql.MySQLError as err:
    # 4. Rollback the transaction
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Close the connection and release resources
    conn.close()
```

#### Querying Data

1. Query the department table data.

```Python
import pymysql

# 1. Create a connection (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Get a cursor object (Cursor)
    with conn.cursor() as cursor:
        # 3. Send SQL statement to the database server via cursor object
        cursor.execute('select `dno`, `dname`, `dloc` from `tb_dept`')
        # 4. Fetch data via cursor object
        row = cursor.fetchone()
        while row:
            print(row)
            row = cursor.fetchone()
except pymysql.MySQLError as err:
    print(type(err), err)
finally:
    # 5. Close the connection and release resources
    conn.close()
```
>**Note**: In the code above, we use a `while` loop to fetch query results row by row. This approach is particularly suitable for scenarios where the query results have a very large number of rows. If you use `fetchall` to fetch all records at once into a nested tuple, it would cause very large memory overhead, which is not a good idea in many scenarios. If you do not want to use a `while` loop, you can also consider using the `iter` function to construct an iterator for row-by-row fetching. Interested readers can explore this on their own.

2. Paginated query of the employee table data.

```Python
import pymysql

page = int(input('Page number: '))
size = int(input('Page size: '))

# 1. Create a connection (Connection)
con = pymysql.connect(host='127.0.0.1', port=3306,
                      user='guest', password='Guest.618',
                      database='hrs', charset='utf8')
try:
    # 2. Get a cursor object (Cursor)
    with con.cursor(pymysql.cursors.DictCursor) as cursor:
        # 3. Send SQL statement to the database server via cursor object
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal` from `tb_emp` order by `sal` desc limit %s,%s',
            ((page - 1) * size, size)
        )
        # 4. Fetch data via cursor object
        for emp_dict in cursor.fetchall():
            print(emp_dict)
finally:
    # 5. Close the connection and release resources
    con.close()
```

### Case Study

Below we present an example of exporting database table data to an Excel file. We need to first install the `openpyxl` third-party library with the following command.

```Bash
pip install openpyxl
```

Next, the code below exports all employees' number, name, position, monthly salary, allowance, and department name from the `hrs` database to an Excel file.

```Python
import openpyxl
import pymysql

# Create a workbook object
workbook = openpyxl.Workbook()
# Get the default worksheet
sheet = workbook.active
# Modify the worksheet title
sheet.title = 'Employee Basic Information'
# Add headers to the worksheet
sheet.append(('Employee No.', 'Name', 'Position', 'Monthly Salary', 'Allowance', 'Department'))
# Create a connection (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # Get a cursor object (Cursor)
    with conn.cursor() as cursor:
        # Execute SQL statement via cursor object
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal`, coalesce(`comm`, 0), `dname` '
            'from `tb_emp` natural join `tb_dept`'
        )
        # Fetch data via cursor
        row = cursor.fetchone()
        while row:
            # Write data to the worksheet row by row
            sheet.append(row)
            row = cursor.fetchone()
    # Save the workbook
    workbook.save('hrs.xlsx')
except pymysql.MySQLError as err:
    print(err)
finally:
    # Close the connection and release resources
    conn.close()
```

You can refer to the example above and try importing data from an Excel file into a specified table in a specified database to see if you can do it successfully.
