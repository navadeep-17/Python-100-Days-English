## Creating Reports

### Exporting Excel Reports

Reports are formats that dynamically display data using tables, charts, and other formats, so some people use this formula to describe reports:

```
Report = Diverse Formats + Dynamic Data
```

Many third-party libraries support writing Excel files in Python programs, including [`xlwt`](<https://xlwt.readthedocs.io/en/latest/>), [`xlwings`](<https://docs.xlwings.org/en/latest/quickstart.html>), [`openpyxl`](<https://openpyxl.readthedocs.io/en/latest/>), [`xlswriter`](<https://xlsxwriter.readthedocs.io/>), and more. Although xlwt only supports writing xls format Excel files, its performance is quite good. Below, we use `xlwt` as an example to demonstrate how to export Excel reports in a Django project.

Install `xlwt`.

```Bash
pip install xlwt
```

View function for exporting an Excel spreadsheet containing all teacher information.

```Python
def export_teachers_excel(request):
    # Create a workbook
    wb = xlwt.Workbook()
    # Add a worksheet
    sheet = wb.add_sheet('Teacher Information')
    # Query all teacher information
    queryset = Teacher.objects.all()
    # Write the header to the Excel sheet
    colnames = ('Name', 'Introduction', 'Upvotes', 'Downvotes', 'Subject')
    for index, name in enumerate(colnames):
        sheet.write(0, index, name)
    # Write teacher data to cells
    props = ('name', 'detail', 'good_count', 'bad_count', 'subject')
    for row, teacher in enumerate(queryset):
        for col, prop in enumerate(props):
            value = getattr(teacher, prop, '')
            if isinstance(value, Subject):
                value = value.name
            sheet.write(row + 1, col, value)
    # Save the Excel file
    buffer = BytesIO()
    wb.save(buffer)
    # Write binary data to the response body and set the MIME type
    resp = HttpResponse(buffer.getvalue(), content_type='application/vnd.ms-excel')
    # Chinese filenames need to be percent-encoded
    filename = quote('teachers.xls')
    # Tell the browser to download the file and specify the filename via response header
    resp['content-disposition'] = f'attachment; filename*=utf-8\'\'{filename}'
    return resp
```

Map the URL.

```Python
urlpatterns = [

    path('excel/', views.export_teachers_excel),

]
```

### Exporting PDF Reports

In a Django project, if you need to export PDF reports, you can use the third-party library `reportlab` to generate PDF file content, then output the file's binary data to the browser and specify the MIME type as `application/pdf`. The specific code is shown below.

```Python
def export_pdf(request: HttpRequest) -> HttpResponse:
    buffer = io.BytesIO()
    pdf = canvas.Canvas(buffer)
    pdf.setFont("Helvetica", 80)
    pdf.setFillColorRGB(0.2, 0.5, 0.3)
    pdf.drawString(100, 550, 'hello, world!')
    pdf.showPage()
    pdf.save()
    resp = HttpResponse(buffer.getvalue(), content_type='application/pdf')
    resp['content-disposition'] = 'inline; filename="demo.pdf"'
    return resp
```

For details on how to customize PDF report content with `reportlab`, you can refer to the reportlab [official documentation](https://www.reportlab.com/docs/reportlab-userguide.pdf).

### Generating Frontend Statistical Charts

If your project needs to generate frontend statistical charts, you can use Baidu's [ECharts](<https://echarts.baidu.com/>). The specific approach is that the backend provides data interfaces to return the data needed by the statistical charts, and the frontend uses ECharts to render bar charts, line charts, pie charts, scatter plots, and other charts. For example, if we want to generate a report that shows the upvote and downvote counts for all teachers, we can do it as follows.

```Python
def get_teachers_data(request):
    queryset = Teacher.objects.all()
    names = [teacher.name for teacher in queryset]
    good_counts = [teacher.good_count for teacher in queryset]
    bad_counts = [teacher.bad_count for teacher in queryset]
    return JsonResponse({'names': names, 'good': good_counts, 'bad': bad_counts})
```

Map the URL.

```Python
urlpatterns = [
    path('teachers_data/', views.get_teachers_data),
]
```

Use ECharts to generate a bar chart.

```HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Teacher Rating Statistics</title>
</head>
<body>
    <div id="main" style="width: 600px; height: 400px"></div>
    <p>
        <a href="/">Back to Home</a>
    </p>
    <script src="https://cdn.bootcss.com/echarts/4.2.1-rc1/echarts.min.js"></script>
    <script>
        var myChart = echarts.init(document.querySelector('#main'))
        fetch('/teachers_data/')
            .then(resp => resp.json())
            .then(json => {
                var option = {
                    color: ['#f00', '#00f'],
                    title: {
                        text: 'Teacher Rating Statistics'
                    },
                    tooltip: {},
                    legend: {
                        data:['Upvotes', 'Downvotes']
                    },
                    xAxis: {
                        data: json.names
                    },
                    yAxis: {},
                    series: [
                        {
                            name: 'Upvotes',
                            type: 'bar',
                            data: json.good
                        },
                        {
                            name: 'Downvotes',
                            type: 'bar',
                            data: json.bad
                        }
                    ]
                }
                myChart.setOption(option)
            })
    </script>
</body>
</html>
```
