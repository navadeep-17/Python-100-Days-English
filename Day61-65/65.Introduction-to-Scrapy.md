## Introduction to the Scrapy Web Crawling Framework

After writing many crawler programs, you'll find that each time you write a crawler, you need to implement page fetching, page parsing, crawler scheduling, exception handling, and anti-scraping countermeasures from scratch. Much of this work is simple and tedious repetitive labor. So, is there any way to improve our efficiency in writing crawler code? The answer is yes - use a crawling framework. Among all crawling frameworks, Scrapy is probably the most popular and powerful one.

### Scrapy Overview

Scrapy is a very popular web crawling framework based on Python that can be used to scrape web sites and extract structured data from pages. #### Scrapy Components

Let's first talk about the components in Scrapy.

1. Scrapy Engine: Controls the overall data processing flow of the system.
2. Scheduler: The scheduler receives requests from the engine, queues them, and returns them when the engine makes requests.
3. Downloader: The downloader's main responsibility is to fetch web pages and return the web page content to the spiders.
4. Spiders: Spiders are user-defined classes for parsing web pages and scraping specific URLs. Each spider can handle one domain or a group of domains. Simply put, they are modules for defining the scraping and parsing rules for specific websites.
5. Item Pipeline: The pipeline's main responsibility is processing data items extracted from web pages by the spiders. Its main tasks are cleaning, validating, and storing data. When a page is parsed by a spider, it is sent to the item pipeline and processed through several specific steps in order. Each item pipeline component is a Python class that receives data items and executes methods to process them, while also determining whether to continue to the next step in the pipeline or discard the item. Tasks typically performed by item pipelines include: cleaning HTML data, validating parsed data (checking if items contain required fields), checking for duplicate data (discarding if duplicate), and storing parsed data in databases (relational databases or NoSQL databases).
6. Middlewares: Middlewares are a hook framework between the engine and other components, primarily designed to provide custom code to extend Scrapy's functionality, including downloader middlewares and spider middlewares.

#### Data Processing Flow

Scrapy's entire data processing flow is controlled by the engine. The typical operational flow includes the following steps:

1. The engine asks the spider which website needs to be processed and has the spider hand over the first URL to be processed.

2. The engine tells the scheduler to place the URL that needs processing into the queue.

3. The engine retrieves the next page to crawl from the scheduler.

4. The scheduler returns the next URL to crawl to the engine, which sends it to the downloader through the downloader middleware.

5. When the web page has been downloaded by the downloader, the response content is sent to the engine through the downloader middleware. If the download fails, the engine notifies the scheduler to record this URL for re-downloading later.

6. The engine receives the response from the downloader and sends it to the spider for processing through the spider middleware.

7. The spider processes the response and returns the scraped data items, along with new URLs that need to be followed, to the engine.

8. The engine sends the scraped data items to the item pipeline and sends the new URLs to the scheduler to be placed in the queue.

Steps 2 through 8 above repeat continuously until there are no more URLs to request in the scheduler, at which point the crawler stops working.

### Installing and Using Scrapy

You can use Python's package management tool `pip` to install Scrapy.

```Shell
pip install scrapy
```

Use the `scrapy` command in the command line to create a project named `demo`.

```Bash
scrapy startproject demo
```

The project's directory structure is shown below.

```Shell
demo
|____ demo
|________ spiders
|____________ __init__.py
|________ __init__.py
|________ items.py
|________ middlewares.py
|________ pipelines.py
|________ settings.py
|____ scrapy.cfg
```

Switch to the `demo` directory and use the following command to create a spider named `douban`.

```Bash
scrapy genspider douban movie.douban.com
```

#### A Simple Example

Next, we'll implement a crawler that scrapes the movie titles, ratings, and memorable quotes from Douban Movies Top 250.

1. Define fields in the `Item` class in `items.py`. These fields are used to store data and facilitate subsequent operations.

   ```Python
   import scrapy


   class DoubanItem(scrapy.Item):
       title = scrapy.Field()
       score = scrapy.Field()
       motto = scrapy.Field()
   ```

2. Modify the file named `douban.py` in the `spiders` folder. This is the core of the spider program, and we need to add page parsing code. Here, we can obtain movie information by parsing the `Response` object, as shown in the code below.

   ```Python
   import scrapy
   from scrapy import Selector, Request
   from scrapy.http import HtmlResponse

   from demo.items import MovieItem


   class DoubanSpider(scrapy.Spider):
       name = 'douban'
       allowed_domains = ['movie.douban.com']
       start_urls = ['https://movie.douban.com/top250?start=0&filter=']

       def parse(self, response: HtmlResponse):
           sel = Selector(response)
           movie_items = sel.css('#content > div > div.article > ol > li')
           for movie_sel in movie_items:
               item = MovieItem()
               item['title'] = movie_sel.css('.title::text').extract_first()
               item['score'] = movie_sel.css('.rating_num::text').extract_first()
               item['motto'] = movie_sel.css('.inq::text').extract_first()
               yield item
   ```
   As you can see from the code above, we can use CSS selectors for page parsing. Of course, if you prefer, you can also use XPath or regular expressions for page parsing, with the corresponding methods being `xpath` and `re`.

   If we also want to generate subsequent crawling requests, we can use `yield` to produce `Request` objects. The `Request` object has two very important attributes: `url`, which represents the address to request, and `callback`, which represents the callback function to execute after receiving the response. We can slightly modify the code above.

   ```Python
   import scrapy
   from scrapy import Selector, Request
   from scrapy.http import HtmlResponse

   from demo.items import MovieItem


   class DoubanSpider(scrapy.Spider):
       name = 'douban'
       allowed_domains = ['movie.douban.com']
       start_urls = ['https://movie.douban.com/top250?start=0&filter=']

       def parse(self, response: HtmlResponse):
           sel = Selector(response)
           movie_items = sel.css('#content > div > div.article > ol > li')
           for movie_sel in movie_items:
               item = MovieItem()
               item['title'] = movie_sel.css('.title::text').extract_first()
               item['score'] = movie_sel.css('.rating_num::text').extract_first()
               item['motto'] = movie_sel.css('.inq::text').extract_first()
               yield item

           hrefs = sel.css('#content > div > div.article > div.paginator > a::attr("href")')
           for href in hrefs:
               full_url = response.urljoin(href.extract())
               yield Request(url=full_url)
   ```

   At this point, we can already run the crawler with the following command.

   ```Shell
   scrapy crawl movie
   ```

   You can see the scraped data in the console. If you want to save this data to a file, you can use the `-o` parameter to specify the file name. Scrapy supports exporting scraped data as JSON, CSV, XML, and other formats.

   ```Shell
   scrapy crawl moive -o result.json
   ```

   You may have noticed that the JSON file obtained from running the crawler contains `275` entries, because the first page was scraped repeatedly. To solve this problem, we can slightly adjust the code above by not parsing URLs for new pages in the `parse` method. Instead, we prepare the URLs of pages to crawl in advance through the `start_requests` method. The adjusted code is shown below.

   ```Python
   import scrapy
   from scrapy import Selector, Request
   from scrapy.http import HtmlResponse

   from demo.items import MovieItem


   class DoubanSpider(scrapy.Spider):
       name = 'douban'
       allowed_domains = ['movie.douban.com']

       def start_requests(self):
           for page in range(10):
               yield Request(url=f'https://movie.douban.com/top250?start={page * 25}')

       def parse(self, response: HtmlResponse):
           sel = Selector(response)
           movie_items = sel.css('#content > div > div.article > ol > li')
           for movie_sel in movie_items:
               item = MovieItem()
               item['title'] = movie_sel.css('.title::text').extract_first()
               item['score'] = movie_sel.css('.rating_num::text').extract_first()
               item['motto'] = movie_sel.css('.inq::text').extract_first()
               yield item
   ```

3. If you want to persist the crawled data, you can process the `Item` objects produced by the spider program in the item pipeline. For example, we can use `openpyxl`, which we covered earlier, to manipulate Excel files and write data to an Excel file, as shown in the code below.

   ```Python
   import openpyxl

   from demo.items import MovieItem


   class MovieItemPipeline:

       def __init__(self):
           self.wb = openpyxl.Workbook()
           self.sheet = self.wb.active
           self.sheet.title = 'Top250'
           self.sheet.append(('Title', 'Rating', 'Quote'))

       def process_item(self, item: MovieItem, spider):
           self.sheet.append((item['title'], item['score'], item['motto']))
           return item

       def close_spider(self, spider):
           self.wb.save('douban_movie_data.xlsx')
   ```

   The `process_item` and `close_spider` above are both callback methods (hook functions), which simply means they are methods that the Scrapy framework will automatically call. When the spider program produces an `Item` object and hands it to the engine, the engine passes the `Item` object to the item pipeline, and at that point the `parse_item` method of our configured pipeline gets executed, so we can obtain data and perform persistence operations in that method. The other method, `close_spider`, is automatically executed before the crawler finishes running. In the code above, we perform the Excel file saving operation here. I'm sure this code is easy for everyone to understand.

   In summary, item pipelines can help us accomplish the following operations:

   - Clean HTML data and validate scraped data.
   - Discard duplicate and unnecessary content.
   - Persist the scraped results.

4. Modify the `settings.py` file to configure the project. The main settings that need to be modified are as follows.

   ```Python
   # User agent
   USER_AGENT = 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_14_6) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/92.0.4515.159 Safari/537.36'

   # Number of concurrent requests
   CONCURRENT_REQUESTS = 4

   # Download delay
   DOWNLOAD_DELAY = 3
   # Randomize download delay
   RANDOMIZE_DOWNLOAD_DELAY = True

   # Whether to obey the robots protocol
   ROBOTSTXT_OBEY = True

   # Configure item pipelines
   ITEM_PIPELINES = {
      'demo.pipelines.MovieItemPipeline': 300,
   }
   ```

   > **Note**: The `ITEM_PIPELINES` option in the configuration file above is a dictionary that can configure multiple data processing pipelines. The number at the end represents execution priority, with smaller numbers being executed first.
