## Pandas In Depth - 2

If you use pandas for data analysis, `DataFrame` is certainly the most widely used type. It can be used to store and process heterogeneous two-dimensional data. The term "heterogeneous" here means that each column in a `DataFrame` can have a different data type, which is what distinguishes it from a NumPy two-dimensional array. `DataFrame` provides an extremely rich set of attributes and methods to help us perform a series of operations such as reshaping, cleaning, preprocessing, pivoting, and presenting data.

### Creating DataFrame Objects

#### Creating DataFrame Objects from 2D Arrays

Code:

```python
scores = np.random.randint(60, 101, (5, 3))
courses = ['语文', '数学', '英语']
stu_ids = np.arange(1001, 1006)
df1 = pd.DataFrame(data=scores, columns=courses, index=stu_ids)
```

#### Creating DataFrame Objects by Reading CSV Files

You can use the `read_csv` function from the `pandas` module to read CSV files. The `read_csv` function has many parameters; below are some of the more important ones.

- `sep` / `delimiter`: Delimiter, defaults to `,`.
- `header`: Position of the header (column index), defaults to `infer`, using the first row's content as the header (column index).
- `index_col`: Column to use as the row index (labels).
- `usecols`: Columns to load, can use column numbers or column names.
- `true_values` / `false_values`: Which values should be treated as boolean `True` / `False`.
- `skiprows`: Rows to skip, specified by row number, index, or function.
- `skipfooter`: Number of rows at the end to skip.
- `nrows`: Number of rows to read.
- `na_values`: Which values should be treated as null values.
- `iterator`: When set to `True`, the function returns an iterator object.
- `chunksize`: Used with the parameter above to set the amount of data retrieved per iteration.

Code:

```python
df3 = pd.read_csv('data/2018年北京积分落户数据.csv', index_col='id')
df3
```

> **Tip**: The CSV file in the code above is accessed using a relative path, meaning there is a folder named `data` in the current working directory, and the file "2018年北京积分落户数据.csv" is in that folder. If you are using Windows, it is recommended to use `/` instead of `\` for path separators. If you want to use `\`, it is recommended to add an `r` before the string to use a raw string and avoid escape characters, for example `r'c:\new\data\2018年北京积分落户数据.csv'`.

| `shape`        | Shape of the `DataFrame` object (rows and columns)   |
| `size`         | Number of elements in the `DataFrame` object         |
| `values`       | 2D array corresponding to the `DataFrame` object's data |

### Working with Data

#### Indexing and Slicing

To get a specific column from a `DataFrame`, for example to retrieve the `ename` column from `emp_df`, you can use either of the following two approaches.

```python
emp_df.ename
```

Or

```python
emp_df['ename']
```

Running the code above, you'll notice that we get a `Series` object. In fact, a `DataFrame` object is the result of combining multiple `Series` objects together.

To get a specific row from a `DataFrame`, you can use integer indexing or the custom index we set. For example, to retrieve the data for the employee with number `2056`, the code is as follows.

```python
emp_df.iloc[1]
```

Or

```python
emp_df.loc[2056]
```

By running the code above, we can see that retrieving a single row or column from a `DataFrame` both return a `Series` object. Of course, we can also use fancy indexing to get data from multiple rows or columns, and the result of fancy indexing is still a `DataFrame` object.

Getting multiple columns:

```python
emp_df[['ename', 'job']]
```

Getting multiple rows:

```python
emp_df.loc[[2056, 7800, 3344]]
```

To get or modify the data in a specific cell of a `DataFrame` object, you need to specify both the row and column indices. For example, to get the position information of the employee with number `2056`, the code is as follows.

```python
emp_df['job'][2056]
```

Or

```python
emp_df.loc[2056]['job']
```

Or

```python
emp_df.loc[2056, 'job']
```

We recommend using the third approach, because it only performs one indexing operation. If you want to change this employee's position to "架构师" (Architect), you can use the following code.

```python
emp_df.loc[2056, 'job'] = '架构师'
```

Of course, we can also use slicing operations to get multiple rows and columns, which you've surely already thought of.

```python
emp_df.loc[2056:3344]
```

#### Data Filtering

We mentioned fancy indexing above, and you've probably already thought of boolean indexing. Just like `ndarray` and `Series`, we can use boolean indexing to filter data in a `DataFrame` object. For example, to filter employees from `emp_df` whose monthly salary exceeds `3500`, the code is as follows.

```python
emp_df[emp_df.sal > 3500]
```

Output:

```
        ename    job        mgr      sal     comm    dno
eno
2056    乔峰      分析师      7800.0   5000    1500.0    20
3251    张翠山    程序员      2056.0    4000    NaN      20
5566    宋远桥    会计师      7800.0    4000    1000.0   10
7800    张三丰    总裁        NaN      9000    1200.0    20
```

Of course, we can also combine multiple conditions for data filtering. For example, to filter employees from `emp_df` whose monthly salary exceeds `3500` and who are in department `20`, the code is as follows.

```python
emp_df[(emp_df.sal > 3500) & (emp_df.dno == 20)]
```

Output:

```
        ename    job        mgr      sal     comm    dno
eno
2056    乔峰      分析师      7800.0   5000   1500.0    20

7800    张三丰     总裁       NaN      9000   1200.0    20
```

In addition to using boolean indexing, the `query` method of `DataFrame` objects can also be used for data filtering. The `query` method takes a string parameter that represents the expression used to filter data, and it is more in line with Python programmers' usage habits. Below, we use the `query` method to reproduce the effect above. The code is shown below.

```python
emp_df.query('sal > 3500 and dno == 20')
```
