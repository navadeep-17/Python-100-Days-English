### What Is Machine Learning

Humans learn through two methods: memorization and generalization. Through memorization, we accumulate individual facts; through generalization, we derive new facts from existing ones. Machine learning endows machines with the ability to learn knowledge from data — this process does not require human assistance (providing explicit rules). In other words, machine learning focuses on learning a pattern from data, even if the data itself contains issues (noise), which is the fundamental difference between machine learning algorithms and traditional algorithms. Traditional algorithms require the computer to be told how to find answers from complex systems, using the computer's processing power to find optimal results. The biggest drawback of traditional algorithms is that humans must first know what the optimal solution is, whereas machine learning algorithms do not require humans to tell the model the optimal solution. Instead, we provide example data related to the problem.

We can categorize the problems that computers need to solve into four types, based on whether the input is precise or fuzzy and whether the output is optimal or satisfactory. We can create the following table. As shown, traditional algorithms excel at solving only the first type of problem, while machine learning is better suited for the third and fourth types. The second type basically belongs to NP problems (non-deterministic polynomial-time problems), including the traveling salesman problem, graph coloring problem, set cover problem, etc. We typically use heuristic algorithms (such as simulated annealing, genetic algorithms, etc.) or approximation algorithms to solve these problems, though machine learning algorithms can also provide satisfactory solutions for them.

<img src="res/01_four_kinds_problems.png" style="zoom:45%;">

Of course, machine learning algorithms are not flawless. When training models with data, we need to use preprocessed and cleaned data. If the data quality is very poor, it is difficult to train a good model — this is what we often call GIGO (Garbage In Garbage Out). To use machine learning, we also need to determine whether some relationship exists between the variables, as machine learning cannot handle data where no relationship exists. Most of the time, machine learning models output a series of numbers and metrics that require human interpretation to make decisions, assess the model's quality, and determine how the model should be deployed in actual business scenarios. Typically, the data we use to train models contains noisy data, and many machine learning models are very sensitive to noise. If we cannot handle this noisy data well, it will be difficult to obtain a good model.

### Steps of Machine Learning

The implementation steps of machine learning are typically divided into multiple stages, from problem definition and data preparation to model deployment and maintenance. Each step is very important, as described below.

1. **Define the Problem**. First, we need to understand the business context and clarify the nature and type of the problem, which directly affects subsequent data collection, feature engineering, algorithm selection, and evaluation metric determination.

2. **Data Collection**. Training machine learning models requires large amounts of data, which may include structured data (databases, Excel spreadsheets, etc.), unstructured data (text, images, audio, video, etc.), and other types of datasets.

3. **Data Cleaning**. Data cleaning ensures data quality is high and suitable for model training. This specifically includes: handling missing values and outliers, data standardization and normalization, special encoding, feature engineering, etc.

4. **Data Splitting**. To evaluate the generalization ability of a machine learning model, data needs to be split into training and test sets. Additionally, cross-validation may be used to divide data into multiple subsets, with each subset taking turns as the validation set, allowing for hyperparameter tuning.

5. **Model Selection**. For classification, regression, clustering, and deep learning problems, the machine learning algorithms or models we choose differ.

6. **Model Training**. Train the model using the training set so that the model can learn the relationship between input features and targets. Additionally, every machine learning algorithm has hyperparameters that need to be tuned based on the data and task.

7. **Model Evaluation**. The primary goal of model evaluation is to determine the model's performance on new data (test set), ensuring the model has not overfitted or underfitted, as shown in the figure below. Underfitting leads to poor prediction performance, while overfitting leads to a lack of generalization ability, i.e., poor performance on the test set and new data. Of course, to improve the model's performance or adaptability, tuning through regularization, ensemble learning, algorithm adjustments, and other methods may be necessary.

    <img src="res/01_overfitting_vs_underfitting.png" style="zoom:85%;">

8. **Model Deployment**. When you are satisfied with the model's performance, you can deploy the model to a production environment for real-time or batch predictions. We monitor the model's performance in actual applications to ensure it maintains good prediction results. If model performance degrades, retraining or adjustments may be needed.

9. **Model Maintenance**. Machine learning models are not static. Over time, models may need to be maintained through retraining, incremental learning, and other methods to sustain their performance.

#### kNN Algorithm

To predict monthly online shopping expenditure based on monthly income, the most intuitive idea is to turn the historical data into a dictionary, with monthly income as the keys and monthly online shopping expenditure as the corresponding values, so that we can look up expenditure by income, as shown below.

```python
sample_data = {key: value for key, value in zip(x, y)}
```

However, the input monthly income may not correspond to a key in the dictionary. Without a key, we cannot retrieve the corresponding value. In this case, we can find the k keys closest to the input monthly income, calculate the average of the values corresponding to these k keys, and use this average as the prediction for monthly online shopping expenditure. This method is the simplest algorithm in machine learning — the k-nearest neighbors algorithm (kNN). It is a non-parametric statistical method used for classification and regression. Below, we implement the kNN algorithm using native Python code without using third-party libraries like NumPy, SciPy, or Scikit-Learn, primarily to help you understand the algorithm's principles.

```python
import heapq
import statistics


def predict_by_knn(history_data, param_in, k=5):
    """Make predictions using the kNN algorithm
    :param history_data: historical data
    :param param_in: model input
    :param k: number of neighbors (default is 5)
    :return: model output (predicted value)
    """
    neighbors = heapq.nsmallest(k, history_data, key=lambda x: (x - param_in) ** 2)
    return statistics.mean([history_data[neighbor] for neighbor in neighbors])
```

In the code above, we use `nsmallest` from Python's `heapq` module to find the k smallest elements from the historical data. Through the `key` parameter of this function, we define "smallest" as having the smallest error compared to the input parameter `param_in`. Since errors can be positive or negative, we typically need to square them or take the absolute value. For calculating the arithmetic mean, we use the `mean` function from Python's `statistics` module. For those unfamiliar with the `heapq` and `statistics` modules, please refer to the official Python documentation — we will not go into further detail here. Next, we use the function above to predict monthly online shopping expenditure, as shown in the code below.

```python
incomes = [1800, 3500, 5200, 6600, 13400, 17800, 20000, 30000]
for income in incomes:
    print(f'Monthly income: {income:>5d} yuan, Monthly online shopping expenditure: {predict_by_knn(sample_data, income):>6.1f} yuan')
```

From the output above, we can see a drawback of the kNN algorithm: missing or imbalanced sample data can lead to very poor prediction results. The predicted online shopping expenditure for monthly incomes of `17800` yuan, `20000` yuan, and `30000` yuan are all `6044.4` yuan because the maximum monthly income in the historical data is `19880`, so the k nearest neighbors for all of them are identical, resulting in the same predicted expenditure. Similarly, the predicted online shopping expenditure for monthly incomes of `1800` yuan and `3500` yuan are also the same because their k nearest neighbors are identical as well. Of course, the kNN algorithm implementation above has other issues. You may notice that in the `predict_by_knn` function, every time we search for the k nearest neighbors, we traverse the entire historical dataset. If the dataset is very large, this would incur significant overhead.

#### Regression Model

Let us take a different approach to predict online shopping expenditure. We plot the monthly income and monthly online shopping expenditure as the x and y coordinates respectively to create a scatter plot. Since online shopping expenditure has a strong positive correlation with monthly income, this means we can find a straight line to fit these historical data points. We call the equation of this line $\small{y = aX + b}$ the regression equation or regression model, as shown in the figure below.

<img src="res/01_regression_model.png" style="zoom:50%;">

Now, our problem becomes how to use the collected historical data to calculate the slope $\small{a}$ and intercept $\small{b}$ of the regression model. To evaluate the quality of the regression model, i.e., whether the calculated slope and intercept are ideal, we can first define an evaluation criterion. A simple and intuitive criterion is to substitute the monthly income $\small{X}$ into the regression model to calculate the predicted monthly online shopping expenditure $\small{\hat{y}}$. The smaller the error between the predicted value $\small{\hat{y}}$ and the actual value $\small{y}$, the better our regression model is. As mentioned earlier, when calculating errors, we typically need to take the absolute value or square them. We can use the mean of squared errors as the evaluation criterion, commonly called Mean Squared Error (MSE), as shown below.

$$
MSE = \frac{1}{n}{\sum_{i=1}^{n}(y_{i} - \hat{y_{i}})^{2}}
$$

Based on the formula above, we can write a function to calculate the Mean Squared Error, commonly called the loss function.

```python
import statistics


def get_loss(X_, y_, a_, b_):
    """Loss function
    :param X_: independent variable of the regression model
    :param y_: dependent variable of the regression model
    :param a_: slope of the regression model
    :param b_: intercept of the regression model
    :return: MSE (Mean Squared Error)
    """
    y_hat = [a_ * x + b_ for x in X_]
    return statistics.mean([(v1 - v2) ** 2 for v1, v2 in zip(y_, y_hat)])
```

The $\small{a}$ and $\small{b}$ that minimize the MSE are called the least squares solution of the regression equation. The next task is to find this least squares solution. Simply put, we need to substitute possible values of $\small{a}$ and $\small{b}$ into the loss function to see which $\small{a}$ and $\small{b}$ minimize the loss function. If we know nothing about the possible values of $\small{a}$ and $\small{b}$, we can search for $\small{a}$ and $\small{b}$ by continuously generating random numbers. This method is called Monte Carlo simulation — in plain terms, random guessing. The code is shown below.

```python
import random

# Initialize the minimum loss as a very large value
min_loss, a, b = 1e12, 0, 0

for _ in range(100000):
    # Obtain slope and intercept by generating random numbers
    _a, _b = random.random(), random.uniform(-2000, 2000)
    # Calculate the regression model's MSE using the loss function
    curr_loss = get_loss(x, y, _a, _b)
    if curr_loss < min_loss:
        # Record a smaller MSE as the minimum loss
        min_loss = curr_loss
        # Record the a and b corresponding to the current minimum loss
        a, b = _a, _b

print(f'MSE = {min_loss}')
print(f'{a = }, {b = }')
```

For those with a stronger mathematical background, we can substitute the regression model into the loss function. Since $\small{X}$ and $\small{y}$ are known historical data, the loss function is actually a function of two variables $\small{a}$ and $\small{b}$, as shown below.

$$
MSE = f(a, b) = \frac{1}{n}{\sum_{i=1}^{n}(y_{i} - (ax_{i} + b))^{2}}
$$

According to the extreme value theorem in calculus, we can take the partial derivatives of $\small{f(a, b)}$ and set them equal to 0, allowing us to calculate the values of $\small{a}$ and $\small{b}$ that minimize $\small{f(a, b)}$:

$$
\frac{\partial{f(a, b)}}{\partial{a}} = -\frac{2}{n}\sum_{i=1}^{n}x_{i}(y_{i} - x_{i}a - b) = 0
$$

$$
\frac{\partial{f(a, b)}}{\partial{b}} = -\frac{2}{n}\sum_{i=1}^{n}(y_i - x_{i}a - b) = 0
$$

Solving the system of equations above yields:

$$
a = \frac{\sum(x_{i} - \bar{x})(y_{i} - \bar{y})}{\sum(x_{i} - \bar{x})^{2}}
$$

$$
b = \bar{y} - a\bar{x}
$$

It should be noted that if the regression model itself is more complex and not as simple as the linear model $\small{y = aX + b}$, it may not be possible to directly solve the equations as above, and other methods must be used to find the extreme points. We will explain this in subsequent content. Returning to our problem, we can calculate the values of $\small{a}$ and $\small{b}$ using the formulas above. For computational convenience, we directly use functions from NumPy below, since NumPy operations are vectorized and typically do not require us to write our own loops. For those unfamiliar with NumPy, please check out my column [*Python-Based Data Analysis*](https://www.zhihu.com/column/c_1217746527315496960).

```python
import numpy as np

x_bar, y_bar = np.mean(x), np.mean(y)
a = np.dot((x - x_bar), (y - y_bar)) / np.sum((x - x_bar) ** 2)
b = y_bar - a * x_bar
print(f'{a = }, {b = }')
```

Output:

```
a = 0.482084452824066, b = -1515.2028590756745
```

In fact, NumPy also provides built-in functions for parameter fitting. You can use the `lstsq` function from the `linalg` module to calculate the least squares solution, or use the `polyfit` function or the `fit` method of the `Polynomial` class to obtain the least squares solution, as shown in the code below. You can check whether the results match those obtained by finding extreme points through partial derivatives above.

```python
a, b = np.polyfit(x, y, deg=1)
print(f'{a = }, {b = }')
```

Or

```python
from numpy.polynomial import Polynomial

b, a = Polynomial.fit(x, y, deg=1).convert().coef
print(f'{a = }, {b = }')
```

> **Note**: The `deg` parameter in the code above represents the highest degree of the polynomial. `deg=1` indicates that we are using a linear regression model.
