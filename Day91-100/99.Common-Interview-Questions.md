## Common Interview Questions

### Computer Science Fundamentals

1. TCP/IP model related questions.

   > Recommended reading: Ruan Yifeng's ["Introduction to Internet Protocols (Part 1)"](http://www.ruanyifeng.com/blog/2012/05/internet_protocol_suite_part_i.html) and ["Introduction to Internet Protocols (Part 2)"](http://www.ruanyifeng.com/blog/2012/06/internet_protocol_suite_part_ii.html).

2. HTTP and HTTPS related questions.

   > Recommended reading: Ruan Yifeng's ["Introduction to HTTP Protocol"](http://www.ruanyifeng.com/blog/2016/08/http.html) and ["Overview of SSL/TLS Protocol Mechanisms"](http://www.ruanyifeng.com/blog/2014/02/ssl_tls.html).

3. Common Linux commands and services.

4. The relationship between processes and threads. When to use multithreading? When to use multiprocessing?

5. Relational database related questions (ACID, transaction isolation levels, locks, SQL optimization).

6. Non-relational database related questions (CAP/BASE, application scenarios).

### Python Fundamentals

1. Which standard libraries and third-party libraries have you used in development?

   > Standard libraries: sys / os / re / math / random / logging / json / pickle / shelve / socket / datetime / hashlib / configparser / urllib / itertools / collections / functools / threading / multiprocess / timeit / atexit / abc / asyncio / base64 / concurrent.futures / copy / csv / operator / enum / heapq / http / profile / pstats / ssl / unittest / uuid
   >
   > Third-party libraries: openpyxl / xlrd / xlwt / PyPDF2 / ReportLab / PyYAML / jieba / pillow / requests / urllib3 / responses / aiohttp / BeautifulSoup4 / lxml / pyquery / PyMySQL / psycopg2 / redis / PyMongo / Peewee / SQLAlchemy / alipay / PyJWT / itsdangerous / celery / flower / elasticsearch-dsl-py / PyCrypto / Paramiko / logbook / nose / pytest / coverage / Selenium / lineprofiler / memoryprofiler / matplotlib / pygal / OpenCV

2. The role, principles, and implementation of decorators.

3. Which magic methods have you used?

   > Recommended reading: ["A Guide to Python's Magic Methods"](https://pycoders-weekly-chinese.readthedocs.io/en/latest/issue6/a-guide-to-pythons-magic-methods.html).

4. Writing comprehensions, generators, and iterators.

5. The underlying implementation of lists, sets, and dictionaries.

6. Garbage collection related questions.

7. Concurrent programming related questions.

8. Coroutines and asynchronous I/O related knowledge.

### Django and Flask

1. What problems does the MVC (MTV) architecture solve?

2. The execution flow of middleware and how to customize middleware.

3. How to design REST data interfaces (URL, domain name, versioning, filtering, status codes, security).

   > Recommended reading: Ruan Yifeng's ["RESTful API Design Guide"](http://www.ruanyifeng.com/blog/2014/05/restful_api.html).

4. CRUD operation related questions using ORM frameworks.

   - How to implement multi-condition combined queries / How to execute raw SQL / How to avoid the N+1 query problem

5. How to execute asynchronous tasks and scheduled tasks.

6. How to implement page caching and query caching? How to warm up the cache?

### Web Scraping Related

1. Components and data processing flow of the Scrapy framework.
2. The purpose of scraping (where in the project the scraped data is needed).
3. Tools used (packet capture, downloading, cleaning, storage, analysis, visualization).
4. Data sources (being able to easily list 10 websites).
5. Data composition (what a particular scraped field is used for in the project).
6. Anti-anti-scraping measures (rate limiting, request headers, Cookie pools, proxy pools, Selenium WebDriver, RoboBrowser, TOR, OCR).
7. Data volume (how much data was ultimately scraped, how many tens of thousands of records or how many GBs of data).
8. Post-processing of data (persistence, data completion, normalization, formatting, migration, classification).

### Data Analysis

1. Scientific computing libraries (common operations in SciPy and NumPy).
2. Data analysis libraries (common algorithms encapsulated in Pandas).
3. Common models and their corresponding scenarios (classification, regression, clustering).
4. What specific metrics were extracted.
5. How to evaluate the quality of models.
6. The practical steps for each model and how to evaluate the results.

### Project Related

1. Project team composition and your role in the team (responsibilities in the project).
2. The business architecture (which modules and sub-modules) and technical architecture (mobile, PC, backend tech stack) of the project.
3. Software configuration management tools (version control, issue management, continuous integration).
4. Core business entities and their attributes, relationships between entities.
5. Which dependency libraries were used and what problems they mainly solve.
6. How the project is deployed and the physical architecture (Nginx, Gunicorn/uWSGI, Redis, MongoDB, MySQL, Supervisor, etc.).
7. How the project is tested, whether any performance tuning was done.
8. What difficulties were encountered in the project and how they were resolved.
