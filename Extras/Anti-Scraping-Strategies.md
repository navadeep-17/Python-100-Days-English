## Common Anti-Scraping Strategies and Countermeasures

1. Construct reasonable HTTP request headers.
   - Accept

   - User-Agent

   - Referer

   - Accept-Encoding

   - Accept-Language
2. Check cookies generated by the website.
   - Useful plugin: [EditThisCookie](http://www.editthiscookie.com/)
   - How to handle cookies dynamically generated by scripts
3. Scrape dynamic content.
   - Selenium + WebDriver
   - Chrome / Firefox - Driver
4. Limit scraping speed.
5. Handle hidden fields in forms.
   - Don't submit the form before reading the hidden fields
   - Use tools like RoboBrowser to assist with form submission
6. Handle CAPTCHAs in forms.
   - OCR (Tesseract) - Generally not considered for commercial projects

   - Professional recognition platforms - Chaojiying / Yundama

7. Avoid "traps."
   - Web pages may contain hidden links designed to lure scrapers (traps or honeypots)
   - Use Selenium + WebDriver + Chrome to determine if a link is visible or in the viewable area
8. Hide your identity.
   - Proxy services - Kuaidaili / Xundaili / Zhimadaili / Mogudaili / Yundaili
