#### After learning Python basics, how do I further improve?

If you've already completed learning Python's basic syntax and want to know how to improve further, you need to first ask yourself: what do you want to use Python for? Currently, the possible career directions after learning Python include the following fields. I've summarized the required technologies for each field as simple keyword summaries.

Of course, the most important thing in learning programming is to improve your overall abilities through hands-on projects. GitHub has a large number of high-quality open-source projects, including excellent Python projects. A project called ["awesome-python-applications"](https://github.com/mahmoud/awesome-python-applications) has categorized these quality resources and provides links. You should check it out. If your self-learning ability isn't very strong, you can learn through free or paid video courses online. If your self-discipline isn't that strong, then the only suggestion is to pay for training classes, because learning in a supervised environment by spending money is indeed a shortcut for many people. But remember: "The master leads you through the door, but the practice is up to you." Choose what you love and give it your all - don't blindly follow trends. This is advice from someone who's been there. I remember when I first entered the software development industry, someone told me something that I'd like to share with everyone as mutual encouragement: "There are two kinds of restless people: those who only watch but don't learn, and those who only learn but don't persist. Restless people are never experts."
